功能發布範圍：`bot`。初版與投票調整成套發布（`both`），見[初版發布紀錄](releases/2026-11-13-flexible-polls-abbreviations.md)；完整結果修正已單獨更新 bot，見[完整結果發布紀錄](releases/2026-11-13-bot-full-abbreviation-results.md)。尚未完成真實 QQ 群聊驗收。

## 使用

在允許指令回覆的群 @ 機器人後發送：

```text
/缩写 yyds
/縮寫 nbnhhsh
/nbnhhsh yyds,nbnhhsh
```

支援空格、半形／全形逗號和頓號分隔；每次最多 5 個不同縮寫，每個限 2–32 位英文字母或數字。不接受整段聊天文字或網址；只傳送正規化的小寫縮寫，不傳送群組、成員、訊息 ID 或 QQ 憑證。不帶參數會顯示用法。結果以純文字列出，按 API 回傳順序顯示全部候選，不限制候選數量、不截斷單個釋義，也不合併重複候選；尚未確認的 `inputting` 結果會另加標示。候選資料來自社群，含義仍需配合語境判斷。

## 敏感詞處理（原始碼已實作，尚未部署）

發布範圍：`bot`。API 候選釋義及回覆中的縮寫名稱，命中本機詞表時將整個命中範圍替換成 `[已遮蔽]`，保留其餘文字、候選數量、原始順序與重複項目，不恢復結果數量或字數限制。簡繁常見用字均列入基礎詞表；匹配會正規化全形／半形、英文字母大小寫，並忽略詞內空白、標點和零寬字元，因此插入星號並不會使詞表失效。

內建詞表 `qgroup_bot/sensitive_words.json` 是自行維護的明確色情／辱罵詞基礎清單，不是 QQ 官方敏感詞庫，不能涵蓋語境、諧音、所有變體及 QQ 的全部規則，可能誤判或漏判，也不保證 QQ 接受消息。正常釋義完整保留；不使用露出一兩個字的方式嘗試避過平台審核。

若需補充規則，可在 bot 可讀路徑放置 UTF-8 JSON 字串陣列，例如 `["需要遮蔽的词"]`，並在 bot 環境設定 `KANBAN_BOT_SENSITIVE_WORDS_FILE` 指向該檔案。額外規則與內建規則合併；檔案修改後，每次查詢（含一小時上游快取命中）都按最新規則重新處理，不需重新呼叫上游。新增環境變數仍須重建 bot 容器載入。已指定的檔案無法讀取或格式錯誤時回覆暫時不可用，不退回未過濾的原文；日誌不記錄命中詞或上游本文。此功能只處理縮寫查詢，不影響活動與主動通知。

本機詞表不產生第三方審核費用，未開通或呼叫付費服務。[騰訊雲文字內容安全購買指南](https://cloud.tencent.com/document/product/1124/37118)（2026-11-13 查閱）列出：首次開通 3,000 條、15 天有效的試用額度；按量後付費人民幣 25 元／萬條，不足萬條按比例計算。每條送審需呼叫一次，單條最多 10,000 個 Unicode 字元；試用到期或用盡後繼續呼叫會轉入計費。若未來接入，需另行配置服務與憑證、確認送審粒度和預算；雲端審核同樣無法保證與 QQ 群審核結果一致。

2026-11-13 本機驗證：258 項 bot 測試通過，包含整詞遮蔽、簡繁／大小寫／全形／分隔字元、快取結果套用最新詞表、錯誤詞表不回傳原文，以及 QQ 發送與輸出預覽日誌只取得處理後文字。測試以隔離資料庫、模擬上游與 QQ 投遞執行，未操作正式服務。

## API 依據

- [官方專案](https://github.com/itorr/nbnhhsh)
- [網站與使用者腳本](https://lab.magiconch.com/nbnhhsh/nbnhhsh.user.js)
- 端點：`POST https://lab.magiconch.com/api/nbnhhsh/guess`
- 標頭：`Content-Type: application/json`
- 本文：`{"text":"yyds,nbnhhsh"}`
- 回傳：JSON 陣列；`name` 為縮寫，`trans` 為釋義列表；沒有正式釋義時可能有 `inputting` 候選。

2026-11-13 實測未帶 API key、Cookie 或 QQ 授權的請求回傳 HTTP 200。這是網站實際使用的公開端點；官方 README 未提供服務等級承諾或明確額度，因此不把目前可呼叫視為長期相容性保證。不呼叫提交詞條的寫入端點。

## 運行與相容性

- 網路 I/O 透過背景執行緒執行，不持有 SQLite 連線、不阻塞 QQ 事件迴圈；網路逾時為 4 秒，完整讀取 API JSON 回應，不以固定回應大小拒絕正常查詢結果。
- 每個 bot 行程共用最多 256 筆、一小時有效的記憶體快取，成功的空結果也快取。每秒最多一次上游請求，同時最多一筆；失敗後暫緩 10 秒，不重試該請求。重啟後快取消失。
- 網路錯誤、429、無效 JSON 或資料結構會回覆暫時不可用；不把上游本文或例外文字送到群裡。詞條中的連結及 @ 提及不轉發。
- 沿用原有群組授權、全域指令回覆開關、模擬／實際發送設定。模擬模式仍執行縮寫查詢，但不向 QQ 投遞。
- 僅修改 `qgroup_bot/`、測試及文件；不變更 schema、outbox、共用設定、網頁入口或 web 運行程式。程式相容性判定為 `bot`；發布時仍須按部署政策核對線上 web 的來源與映像並驗證版本組合，真實 QQ 驗收另行記錄。
