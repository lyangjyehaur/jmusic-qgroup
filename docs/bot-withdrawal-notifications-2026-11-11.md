# 退出與候補遞補群通知

已於 2026-11-11 16:15（Asia/Taipei）成套部署並啟用（設定 4 → 5），詳見[發布紀錄](releases/2026-11-11-bot-withdrawal-notifications.md)。

發布範圍：`both`。web 在同一業務事務產生 outbox，bot 投遞新種類，共用後台設定增加「退出／候补递补」。正式結果另記於發布紀錄。

- `registration_changed` 比較審計前後狀態，僅通知正式／候補轉為已退出、候補轉為正式。管理者撤銷也適用；逾期退出待審、被拒、取消待確認或未接受的邀請保持安靜。整場取消沿用活動取消通知。
- 同次退出及遞補合併一則；增加名額、恢復報名、整組候補拆分產生的獨立遞補也通知。分列本次退出與遞補者、當時總人數、開始倒計時及活動入口，每類最多 10 名並提示其餘人數。
- 只公開既有安全顯示名稱；不序列化退出原因、審批備註、付款／退款、帳號或人員 ID。普通通知凍結入隊事實。尊重可見性、活動同步、全局開關、種類、群目標、勿擾、間隔、模擬與重試政策。
- 通知與業務同一事務，回滾不發；同 revision 重複掛鉤及 HTTP Idempotency-Key 不重複入隊。不補發歷史變動，不改業務狀態機及 schema。
- 新配置預設包含新種類，已保存的選擇維持原樣，需明確開啟。新版 enum／模板 key 無法交給舊後台編輯，故成套發布；回退前在新版移除且僅移除 `registration_changed` 與對應純文字／`@md` 模板，作廢該類待送消息，保留其他最新設定，再恢復已保存的舊映像組合。不得覆蓋現有資料庫。

驗證使用隔離資料庫及模擬 QQ API，不向真實群聊發測試通知。新增 14 項涵蓋退出／審批／管理撤銷、各類遞補、隱私與可見性、回滾／去重、長名單與凍結投遞的測試。

本機完整 Python 測試在 bot 開關 `0`／`1` 各 513 項通過；Node 11 組通過。手冊與簡繁產物已重建，語法及 `git diff --check` 通過。
