# Bot 報名名單（本機完成，未部署）

發布範圍：`both`。web 產生 outbox 快照及後台模板預覽，bot 渲染查詢與投遞；共用核心新增可選 `_roster_lines`，無 schema 或設定變更。

- 單場 `/活动`、`/报名`、`/名额` 與活動發起、成團、安排變更、截止提醒、暫停／恢復報名通知，分開列正式與候補。多活動選單及其他指令不加名單。
- 使用站內顯示名稱／代報稱呼及既有隊列順序，每類最多 10 人、每名最多 24 字；總人數及其餘人數保留。同名不去重。待確認、受邀、已退出不列入；待核准退出及未確認新版安排不改變原報名狀態。
- 僅公開、非草稿、未刪除活動可讀；被動查詢沿用不依賴群同步開關的規則。名稱移除 Markdown、平台提及及裸 URL，不讀取帳號身分或附加報名備註、付款歸屬等資料。
- 普通通知凍結入隊名單，與凍結人數一致；截止提醒發送前重建最新名單。自訂模板同樣自動附名單，無需新增模板變數。先保留必要文案和結算明細；超過 4000 字限制時改為活動頁提示，提示仍放不下則省略名單。
- 新活動保留先建立活動、再報名的審計順序，僅將建立活動的 bot 掛鉤延至發起者自動報名之後；通知與報名仍在同一事務，首次通知不漏掉發起者。
- 舊 outbox 缺少 `_roster_lines` 時照常投遞，不回填新的名單。舊 bot 可忽略此可選欄位，但不保證顯示名單；此次按 `both` 規劃，尚未驗證線上混合版本，不宣稱可以單邊發布。歷史已發消息不回寫，無新增逐人金額或私聊投遞。

驗證使用隔離 SQLite、模擬 QQ API；測試不代表已完成真實群聊驗收。

驗證結果：全套 Python 測試在 `KANBAN_BOT_ENABLED=0` 與 `1` 各通過 488 項（含 10 項名單測試）；Node 測試通過 11 項。手冊及簡繁產物已重建，Python 編譯檢查與 `git diff --check` 通過。
