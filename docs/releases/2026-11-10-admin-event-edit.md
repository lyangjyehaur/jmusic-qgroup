# 管理員協助編輯已發布活動（待發布）

發布範圍：`both`。狀態：本機實作及隔離驗證完成，尚未部署，未更動正式活動資料。

## 變更

- 已授權的管理員帳號在活動詳情使用「管理員協助編輯」，修改有權查看、尚未實際結束／取消／歸檔且未結算的活動安排。
- 可更正名稱、類別、時間／時長／時區、地點、說明、名額與報名截止。費用、可見性、群同步及自訂退出期限仍按原發起者權限處理；原退出期限跟隨報名截止時允許一併同步。
- 每次協助須修改原因，記錄 `event_admin_updated`、實際帳號及修改前後內容，通知原發起者。重要安排變更仍建立不可變安排版本並要求既有參加者重新確認。
- 協助權限不增加 `event_roles`，不轉交所有權、不自動報名，也不授予開始／結束、取消、名單、出席或財務權限。管理員撤銷後，舊頁面的新提交立即被拒絕；已提交請求的查回只返回重新計算的目前權限。
- 支援原有通宵日期選擇、發布前時間確認及本機草稿。活動紀錄中的安排時間按前後快照各自的活動時區顯示。

## 相容性與發布範圍

本次涉及共用權限與活動核心，以及產生群通知／定時提醒的 outbox hook，因此保守按 `both` 評估。沒有 schema 遷移，沒有變更 outbox 的欄位、訊息 kind 或 payload 格式；管理員修改仍產生既有 `conditions_changed` 及提醒。

目前只驗證本機新版組合，尚未取得或驗證正式 web／bot 映像與來源版本的混合組合，不宣稱可直接單邊發布。正式發布前，依 `docs/deployment-policy.md` 記錄兩個服務的實際版本、保全資料並完成相應的隔離相容性驗證。此紀錄沒有正式發布識別、image ID 或發布成功結果。
