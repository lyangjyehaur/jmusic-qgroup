# QQ 登入與明確帳號綁定（20261109-qq1）

- 補上 `/auth/qq/callback`，無參數時提供說明及返回看板連結；合法 OAuth 回調由後端交換 token、驗證 App ID／OpenID 並呼叫 `get_user_info` 讀取暱稱。
- 個人資料提供官方 QQ 登入按鈕與帳號入口。已有活動可先綁定目前帳號；直接 QQ 登入使用該 QQ 的獨立帳號。授權後還需核對確認；同名不合併、綁定衝突不替換。
- session 綁定、10 分鐘一次性 state、回調重放防護、帳號切換檢查、輪替 Cookie、錯誤去敏、官方請求限時與拒絕重導。App Key 只存伺服器 root 0600 設定檔，token 不保存也不回前端。
- Migration 7 僅新增 QQ 映射與授權暫存表。原活動、報名、帳單、款項及群內稱呼不變。
- 官方 QQ 登入按鈕來源：`https://qzonestyle.gtimg.cn/qzone/vas/opensns/res/img/bt_blue_76X24.png`，保持原始圖像與尺寸。

驗證：202 項 Python 測試通過（其中 16 項 QQ／官方回應處理測試）；全部現有 Node 測試與修改的 JavaScript 語法檢查通過。QQ 測試使用隔離資料庫與模擬官方回應，沒有向正式活動寫入測試名額或款項。

限制：應用仍在官方審核中，不能由 get_user_info「已获取」推論正式用戶全部可登入。真實 QQ 授權、官方 get_user_info 回應、手機與跨裝置 QQ 找回仍待本人操作驗證；UnionID、QQ 號碼、群名片、群成員驗證與自動群推送不在本次接入範圍。
