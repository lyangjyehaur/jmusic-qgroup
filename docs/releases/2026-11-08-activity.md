# P2 活动流程发布记录

版本 20261108-4。Python／SQLite／原生前端，沿用 server2 原服务与 8791 端口；1Panel 代理及 TLS 不变。

## 交付

- 草稿、发布、暂停／恢复、最低成团及人工确认、实际开始／结束、归档。
- 预计结束只提醒，不锁定延长；新活动明确活动时区，跨日结束显示日期。
- 地点、时间、注意事项、费用规则等保存安排版本，管理人逐人接受／暂不同意，旧约定保留；提供复制摘要。
- 协办按安排／报名／出席授权，接受后生效；发起者转交需接任者确认，7 天邀请可撤销。
- 独立出席状态、实际到离场时间、结束后带原因更正；现场补录对超额和候补例外分别确认。
- 取消保留名单、账务及收款码，仍可结算；归档继续可查历史、可更正账务。
- 所有业务写入与异动记录、站内通知、请求去重在同一事务内完成；旧缓存重试不重执行业务。

## 验收与迁移

70 项 Python 测试通过；10 项时区及跨日断言通过；4 个前端脚本语法检查通过。浏览器在 390×844、360×740 验证草稿发布、同行报名、安排变更、逐人接受／拒绝、实际开始、迟到、现场补录、协办生成／接受、结束结算、取消、归档及摘要复制。

数据库迁移 2 新增生命周期、安排、权限及出席结构。逐表比较正式快照全部原列和数据，包括图片、账单、历史、已变化的名册及请求结果；连续迁移两次验证幂等性，再校验外键与完整性。上线前最终快照另存，代码与数据恢复分开处理。

已部署至 https://kanban.danndann.cn，线上健康检查为协议 2，5 个新版前端资源逐字节核对通过，公开响应不泄露管理或报名令牌。

正式停机快照包含主库与 WAL 的全部已提交数据，先复制到隔离目录再合并，不由 root 打开实时库迁移。最终源库为 16 个账号／浏览器身份、3 个活动、11 个参加者、9 个报名组、1 笔结算及其历史；所有用户表的原列、原值及图片均保留。新增 3 份原安排基线，未知实际时间、时区及费用规则仍保持未知。

恢复材料位于 server2 的 `/var/backups/qgroup-upgrade-20261108-4/`（root 专用），包括旧代码、完整最终数据库及停机时主库／WAL。新版在线备份 `kanban-20261107-181020.sqlite3` 已验证完整性、外键及所有原值。正式库没有新增测试活动、账号或款项。1Panel 设置未改动。
