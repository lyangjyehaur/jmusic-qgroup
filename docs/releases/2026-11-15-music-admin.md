- 每次管理 API 由主站檢查現有帳號管理權限或管理憑證；寫入另檢查同源及 CSRF。成分服務僅接收私有本機轉接身分，不接收主站 Cookie；公開轉接不能自行提供管理身分。匿名可讀管理頁靜態介面，但管理資料、匯出與操作均需授權。

- 會員刪除及全站重置先同步寫入 erasure ledger，再清理資料及身分；歷史 JSON 下載套用最新 ledger。主站帳號、活動與帳務不刪除。下載的成分 JSON 含私人資料但不含身分庫與管理憑證，不能單獨用於完整恢復登入關聯。
- 壁紙移至資料卷 `walls/`，PNG/JPG/WebP、單張 2 MiB，初始化及更新後保留，納入配對備份。未從舊站另外取得圖片；原有隨附壁紙清單為空，使用者提供的 JSON 不包含圖片檔。
