# 帳號註冊策略（20261109-auth1）

訪客瀏覽不再自動建立帳號。預設新帳號須經 QQ 官方授權，在站內核對並明確確認後才建立；群內稱呼可另外修改。活動、報名及帳務寫入均須已登入。

獨立 `/admin` 管理後台新增「允許免第三方登入註冊」開關，預設關閉。開啟才額外允許只填稱呼建立瀏覽器帳號；關閉後保留既有帳號。一般活動帳號不具管理權。管理憑證僅存摘要，管理寫入有同源、CSRF、版本及追加紀錄保護。

第三方關聯以平台、應用及平台用戶身分區分，預留微信等登入；本版僅提供 QQ。OAuth state 綁定原訪客／帳號與瀏覽器，回調一次性使用，確認後輪替 Cookie，再返回原活動或邀請。App Key 與 token 不進入前端、紀錄或資料庫。

Migration 8 在隔離副本演練兩次並核對舊資料。正式公開前的測試帳號及關聯活動、報名、帳務、圖片完整封存，再建立空白正式庫。
