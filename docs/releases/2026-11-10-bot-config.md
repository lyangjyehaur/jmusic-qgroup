# Bot 後台即時配置

網站管理後台新增 QQ 機器人配置：主動通知／指令回覆分開開關、模擬或實際發送、通知事件、提醒時間、跨午夜勿擾時段、發送間隔、按事件的消息模板與示例預覽。

配置以 SQLite 共用，web 與 bot 無需重啟即可讀取。保留版本檢查、管理會話、同源與 CSRF 驗證；修改與恢復上一版均追加不可變歷史。schema 13 僅新增配置與運行狀態表，不修改既有活動、報名、帳務或消息原文。

關閉通知作廢待送消息，提醒改時重排未來排程，勿擾與頻率延後不計入失敗重試。新版一般通知保留入隊時的事實快照，投遞時套用最新模板，提醒則重算即時人數。既有逐場公開群同步限制保持適用，模板無個人身份或金額變數。

第一次發布仍需更新 web 與 bot 程式並遷移資料庫；之後調整上述配置無需重新建置。正式部署沿用 README 的備份、隔離副本遷移演練與更新流程。
