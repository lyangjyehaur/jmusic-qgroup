# React／Yahha UI 正式發布

2026-11-16 15:07:56（Asia/Taipei）完成 server2 發布。發布範圍：`web`，包含群聚看板及獨立 music 服務；bot 保留原容器、映像及啟動時間。

## 畫面與功能

- 兩站及管理、說明、隱私頁使用 React 19.3.1 與實際 Yahha UI 0.2.0 元件，保留原資料控制器、表單欄位、驗證與 API。建置時將既有畫面操作轉接至 React 邊界，並非全面重寫業務邏輯。依賴鎖版，生成模組、簡繁產物及第三方授權一併發布。
- 成分站依發現、同好、聚會、動態、我的重新組織。移除額外標語與介紹區；排行在中小螢幕改單欄，歌手名稱可換行，分類置於名稱下方，移除擠壓名稱的進度條。驗證寬度含使用者回報的 614px。
- 成分編輯保留未保存草稿，僅有變更時顯示保存列；保存聯絡 QQ 不重載整頁。領域不顯示熟悉程度，細分保留四級選項，分類篩選只列實際存在的分類。
- 聚會移除重複活動列表，以看板活動與報名名單作為分房輸入。保留按房數、每房人數、自訂人數、性別選項、手動調整及分享圖；切換活動或來源失敗時清除舊結果。試算不修改看板報名或正式包房。
