# 第三十一批實作：共用音樂搜尋與成分工作區

日期：2026-11-17（Asia/Taipei）。分支 `codex/unified-rebuild`。發布範圍 **`none`**：本機實作、隔離驗證及原始碼同步，不部署、不整合 main。運行程式影響範圍為新版 web 與其純函式搜尋模組；不修改 Python bot、schema、outbox、群政策或正式資料。

## 詞庫與成分共用一份狀態

`/music` 與 `/me/music` 使用同一個 React 工作區、同一份選擇／程度／保存狀態與同一個 `qgroup:rebuild:music:v1:<scope>` 分頁草稿。詞庫詳情直接選取／取消，側邊已選清單可移除或修改細分四級程度；返回成分編輯延續同一選擇。兩頁切換、搜尋及開關詞條詳情不觸發離站提示，離開工作區仍須明確保留草稿或繼續編輯。

領域最多 5、細分最多 15、合計最多 20；領域沒有程度操作，原程度保留。取消後重新選取仍依既有預設使用程度 3。保存至少一項，兩頁使用原會員／scope／CSRF、成分 ID／epoch／revision、交易與回執端點。操作 UUID 與原 body 在送出前持久保存；保存中或結果未知時，兩頁的選取／移除／程度控制都鎖定，切頁不產生第二個操作。重整或收件匣查回仍須明確確認原操作，不自動重送。

保存列只有修改後出現；保存成功後移除，保留操作結果。手機固定保存列同樣只在修改後出現，長名稱可換行。分類依實際詞庫分組，原生 `details` 支援鍵盤與收合，不為空分類留下容器。已選清單獨立於搜尋／分類，篩選不移除選擇。從活動進入的返回位置與搜尋條件在詞庫／編輯切換時延續。

工作區按 scope 與 music epoch 分隔，登出及成分刪除沿用統一草稿清除；已離開或被撤權的工作區不接納延遲保存回應。損壞草稿必須先保全才可編輯；儲存拒絕阻止保存。進入工作區先確認目前成分，避免建立第一個詞條後使用先前「尚無成分」的快取；未編輯的狀態可採用背景更新，已有修改或原 UUID 的草稿保留原版本。核對最新版本期間鎖定編輯，避免較晚回應覆蓋新的本地選擇。

## 共用搜尋

詞庫與成分編輯使用同一個原生 TypeScript 索引，涵蓋名稱、別名、漢字完整拼音與首字母、英文和假名行首字母。保留原首字母前綴及拼音子字串規則，不擅自把假名改為另一套羅馬字演算法；例如 `yrsk` 對應「ヨルシカ」。名稱／別名以原文顯示，索引沿用既有 NFKC、casefold、零寬移除與 whitespace 正規化。每份詞庫先建索引，輸入時不重建所有讀音。

既有 20,992 字讀音表抽取為 `packages/domain/src/music-search-data.json`；執行 `node tools/rebuild/extract-music-search.mjs --check` 可核對。正式 bundle 只讀 JSON 與 TypeScript，不載入舊網站腳本、DOM 控制器或全域 `window.PY_*`。後端未使用搜尋時不打包讀音表。

兩頁都使用 URL 搜尋／分類／類型參數。清除按鈕保留輸入焦點，Escape 清空搜尋，`/` 聚焦；正在輸入、可編輯元素、IME 組字或 Ctrl／Meta／Alt 組合不攔截。無效篩選值有明確顯示，不把「無結果」偽裝為全部分類。

## 驗證

後端／領域全套 48 個檔案、414 項測試通過。新增 3 項搜尋差分，直接取原 `initialsOf`、`textPinyin`、`matchSearch` 核對全部 20,992 字、假名行、名稱／別名、首字母前綴與拼音子字串，另覆蓋 Unicode 正規化與詞條索引隔離；原 API 411 項回歸維持通過。

Chrome 全站 232 項回歸全部通過，其中新增工作區 9 項，涵蓋搜尋／分類／收合、跨頁選擇與熟悉度、活動返回、原 UUID／body 恢復、5／15 限額、保存中切頁、儲存拒絕／損壞保全、切換帳號、登出與延遲回應。既有建立首詞條後的保存流程驗證了快取競態修正。原本只檢查未修改保存按鈕禁用的斷言改為確認按鈕不存在，對應 M06 要求。

strict TypeScript、重構建置、空隔離庫產物 smoke、既有 UI 產物檢查、讀音資料來源核對、166 項台帳與 `git diff --check` 通過。360px 詞庫詳情、長名稱、已選清單與修改後固定保存列已視覺檢查，沒有水平溢出；保存後固定列移除。前端 bundle 994.15 kB（gzip 292.08 kB）、API 約 557.5 kB；原有大於 500 kB 的前端提示仍存在。已確認 API 產物不包含讀音表。
