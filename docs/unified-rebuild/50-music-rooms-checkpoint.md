日期：2026-11-17（Asia/Taipei）。分支 `codex/unified-rebuild`。發布範圍 **`none`**：本機隔離實作與驗證，未整合 main、未部署。保留 schema 14／94 張表、現有 Python bot 與既有正式分房／結算契約；不建立新投遞者。

## 分房工作區

同好入口提供 `/tools/room-lab`；活動預分包間入口提供同一路由的 `eventId` 上下文。自由試算記住包含本人偏好（可沿用舊站已保存偏好），提供名稱／固定 ID 搜尋、經原查詢權限定位聯絡 QQ、前 16 位推薦與其餘候選換批、全名單分頁、最多 40 人。活動直接使用完整有效名冊，以 attendee／user 對應目前成分；不猜名稱、聯絡 QQ 或同行管理人。正式、候補、待確認及無成分者均保留；超過自動試算上限的人員仍可在正式安排核對。

支援整組合拍分析、按房數／容量／自訂人數分房、已公開男／女性別相同者優先、手動移房、待人工安排、新增／移除空包間及重新計分。無成分者可手動安排但不計分；有成分者須先選入本次試算。每間顯示平均、最低、個人極值、最弱配對、較少共同項者與共同詞條；整組另可展開兩兩配對。整組分析保留已有房間輸入，不以分析結果清掉人工安排。

`music-rooms-v1` 保留舊 Python 的種子、貪心、最多八次局部移動、40 人上限、最少兩房及容量最低二人的既有行為；自訂容量可為一人，跟隨各房排序，避免舊版排序後容量錯位。以實際 `music_site.upstream` 執行差分；匹配 raw 分數只沿用既有精確 half-even 決策，對可證明的浮點半分誤差正規化，不更改分房公式。共同詞條保留分析八項、舊 split 投影五項的相容比較。

## 來源與計算隔離

`GET /api/v2/music/rooms/source` 與 `POST /api/v2/music/rooms/calculate` 要求目前帳號 scope；計算另驗 CSRF、最多 128 KiB 請求、每分鐘 30 次，以及成員／房間唯一、容量守恆與未知人員。來源 hash 綁活動名冊版次、目前成分對應、使用量、公開性別及可採用狀態。私人性別／留言／聯絡資料不進入計算或來源回應。

演算法在最多兩個 worker 執行，V8 old generation 64 MiB、young generation 16 MiB、stack 2 MiB、單次五秒期限；結束後終止 worker 才釋放並行額度。busy、超時、錯誤及關閉不發布晚結果。這些是單一 API 程序的限制，不是部署層的總記憶體、全站或多副本資源配額；正式規模效能仍待驗證。worker 不持有資料庫、憑證或外部投遞 client，計算前後都重驗身份與來源。

草稿以帳號 scope／活動隔離，暫存於 sessionStorage。來源背景刷新不覆寫草稿；來源失敗、名冊／成分變更停用舊分數、分享及採用，需明確核對來源再重新計分。離開有草稿提示；切活動、登出、卸載及失效會取消等待並丟棄晚結果。登出及刪除成分會跨頁清理分房草稿與損壞原稿副本；損壞草稿先另存原始字串再允許建立新試算；儲存失敗不得假報持久成功。跨裝置、IndexedDB／PWA 草稿及切換仍未完成。

## 正式採用與 bot 保全

試算不會直接寫入正式包間。發起者先到既有預分頁預覽分組與未安排人員；已有草稿須明確確認替換。載入沿用既有房間 ID、名稱、付款人；多餘舊房保留空房，新房使用新的正式 ID，避免移除已有款項的房間。仍需填妥付款人、核對人員並確認保存。

保存沿用 `/activities/:id/rooms` 的 owner、revision、活動狀態、房間／帳本保全、UUID 操作回執與追加稽核；新增 optional `music_source_version`，實際寫入前再核對來源。成分變更拒絕舊建議；可重新試算，或明確「轉為手動安排」後自行核對，不能把刷新名冊當作重新計分。已成功的原操作可用相同 payload／key 查回結果，不因後來來源變動重複保存。

預分仍不記帳、不建立結算通知。隔離測試在非空 bot pending／sending／sent／failed／skipped、simulated 與平台未確認狀態，以及設定歷史、runtime、群政策存在時執行採用，逐欄確認不變。實際 Python `qgroup_core.rooms` 能讀取新的預分與 current，`bot_views` 保留正式／候補／待確認統計及既有名冊輸出語意。既有 Python bot 全套回歸另行執行；沒有真實 QQ 呼叫，也未將本批合成測試當成正式運行版本組合或 B01–B15 完整驗收。

## 圖片與介面

自由／活動試算均可先核對分享範圍，再產生圖片、下載、原生分享或複製清單。白名單只含活動／包間名稱、人名、分數、共同詞條及未安排人數，不含 ID、聯絡 QQ、性別或留言。圖片長名換行並省略過長部分，完整內容保留於文字清單；圖片高度設上限，失敗仍可複製全文、重試或手動選取。來源失效會撤銷可用圖片，並釋放舊 object URL／canvas。
