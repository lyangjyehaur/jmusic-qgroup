## 對照方法

同時啟動原型與隔離預覽，以同一個 Chrome、相同粉色主題、1440px／390px 寬度擷取實際頁面，產生左右並排圖。左為原型、右為接入版本。比較布局、元件狀態與共用樣式；兩邊資料來源不同，不把虛構名稱、金額、人數或公開資料複製到產品。

23 組場景、兩種寬度、兩份應用，共 92 個頁面狀態：活動列表、新增、活動詳情、詞庫、氣泡、成分編輯、同好、我的、收件匣、後台、分房、投票、帳本、成分資料、分享、趨勢、圈子、找搭子、帳號、外觀、隱私、詞條對話框、同好對話框。手機與桌面皆擷取，重點區域逐區檢視。

另外量測新增活動按鈕、詞庫主要導覽連結、同好次要導覽連結，在四種配色、兩種寬度、一般／滑過／焦點／按下的 96 組狀態。涵蓋尺寸、間距、字型、邊框、圓角、陰影、焦點、圖示和相對頁首位置。

深色舒適與淺色緊湊各檢查四種配色、兩種寬度、六個場景，共 96 個延伸狀態。深色是已授權的擴充，原型沒有對應的深色參考頁。

## 已修正的落差

| 區域 | 實際問題 | 修正 |
| --- | --- | --- |
| 樣式載入 | 舊版高特異性規則覆蓋原型 | 舊版 CSS 放入 retained layer，原型與 Yahha 元件保持正常優先序 |
| 樣式作用域 | `.my-music-page > .tabs` 等頁面根節點規則未命中 | 產生器同時支援根節點及子節點；body 的視窗最小高度只套在 shell |
| 對話框 | 桌面撐滿視窗、資料欄寬度變零 | 移除 body 高度誤套；恢復直列定義清單及置中對話框 |
| 導覽連結 | 手刻 ActionLink 與原型按鈕造型不一致 | 從同一套公開 Yahha Button 實際樣式產生 anchor bridge，保留連結與路由語意 |
| 活動頁 | 詳情雙重內距、報名區與名單鬆散 | 移除雙重容器內距；恢復左右報名操作與緊湊名單、手機直排操作 |
| 新增活動 | 只改外框，內部仍是舊控制項 | 接入原型欄位、編號分區、欄網格、進階展開與固定儲存列 |
| 成分編輯 | 原生熟悉度選單、重複分類、手機儲存列消失 | 使用原型 Select、獨立領域分組、四種細分程度及常駐手機儲存列 |
| 詞條詳情 | 泛稱標題、缺少底部操作、塞入整份編輯器 | 顯示實際詞條標題，底部返回／編輯操作，僅調整目前詞條程度 |
| 同好卡 | 舊版長頁內容，複製按鈕佔滿版面 | 原型資料列、圖示複製、後端共同喜好與匹配度、完整成分可展開 |
| 隱私與返回 | 同好標題可能閃現舊姓名；複製失敗擠掉手機姓名連結 | 標題依導航及最新權限讀取重設；複製結果獨立佔完整資料列 |
| 同好推薦 | 過多診斷資料直接攤開 | 原型排序工具列、緊湊推薦卡與少量資料名單；完整診斷留在展開區 |
| 個人與子頁 | 回到舊版頁框、活動列過大 | 保留原型個人橫幅與分頁；活動改為緊湊日期列 |
| 帳號 | 直排舊卡片 | 原型雙欄帳號、QQ 綁定、多帳號切換及真實裝置摘要 |
| 外觀與隱私 | 原生選單與直排卡片 | 原型選單、雙欄設定與資料管理；保留系統／明暗、四配色、密度、桌布 |
| 後台 | 首頁只有入口 | 原型分頁與真實成員表格、篩選；完整管理入口與授權流程保留 |

| 分享 | 舊版直排設定與長條白圖 | 原型預覽＋側欄；綠色卡片、詞條分塊；可下載的真實 PNG |
| 帳本 | 舊直列統計 | 個人款項摘要與橫向總額；所有款項、申報、沖正及結清操作仍由原控制器處理 |
| 投票 | 候選缺少原型視覺 | 候選卡片、實際填答分佈及可及的選項控制；修正極端票數的長條溢出 |
| 搜尋與通知 | 舊版清單與內距 | 原型搜尋控制、結果列與通知標記；保留來源網址、待辦與通知分頁 |
| 圈子／趨勢／找搭子 | 額外子頁仍有舊版長卡片與清單 | 圈子卡片網格、趨勢緊湊列與可展開歷史圖、找搭子內容及發布側欄；資料與限制保留 |

## 仍須保留的業務差異

以下沿用使用者已確認的既有功能優先原則，沒有用示例資料補齊畫面：

- 當時將領域熟悉度移除是來源審核漏判；領域與細分均應保留四級操作，已依[恢復紀錄](domain-familiarity-restoration.md)更正。
- 新增活動維持可恢復草稿、明確確認後發布，以及台北時間輸入與獨立顯示時區。原型的直接模擬發布、獨立地址、每人估算金額沒有硬套到不同後端欄位。
- 同好匹配、留言可見、聯絡 QQ 說明、性別公開及私人成分資料遵循原 API；沒有把私人留言改成任意公開留言。
- 詞條沒有描述或相關詞條資料時，不製造介紹或關聯；原有名稱、別名、建立者、選用人數與選取者依實際回應顯示。
- 活動管理、帳本、投票、恢復、裝置與刪除保留完整控制項、確認步驟與結果不明時的恢復。投票仍需提交填答；款項申報不等同確認入帳。
- 帳號、分享與後台的資料量、身分欄位、金額與權限可能與原型不同。共用布局接入不表示整頁像素相等。
- 經專案規則移除的裝飾性介紹不補回。
