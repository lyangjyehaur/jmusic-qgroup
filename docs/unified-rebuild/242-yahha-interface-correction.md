# Yahha UI 介面修正

日期：2026-11-23。影響範圍：`web`；本次發布範圍：`none`，僅更新本機預覽。

新版原本已採 React／TSX、Yahha UI 0.2.0 並載入元件庫 CSS；視覺落差來自自訂藍灰主題及平鋪的操作入口。此次恢復原站的 `pink` 主題、紙面與控制項樣式，保留系統／亮色／深色偏好及壁紙功能。

共用導覽、標題與操作間距統一；活動與詞條的新增操作凸顯為主要入口。活動卡片採 Yahha Badge 顯示分類／狀態。活動詳情將次要操作分成報名與出席、費用與結算、安排與管理，原有連結、權限讀取、重試及跨成分入口均保留。`ActionLink` 用 React Router 原生連結與 Yahha tokens 補足元件庫僅提供 button 的限制，保留路由攔截與新分頁語意。

驗證：

- TypeScript 型別檢查、Vite 前端建置、67 項既有前端單元測試及 diff 檢查通過。
- 無網路／資料庫的 React 渲染檢查通過：活動詳情 16 個目的地、列表 6 個目的地及原生 anchor 語意。
- 本機 HTTP 已提供此次建置的頁面及 CSS；抽查亮／深主題的正文、次要文字、連結及主要操作文字與背景，對比均達 4.5:1。
- 深色端到端案例的預期配色已更新，但本輪尚未執行瀏覽器驗證。瀏覽器控制工具無法連線，不能將本輪記為目視或端到端驗收完成。

本機預覽正常停止再啟動，繼續使用原本的最新線上隔離副本及其工作資料庫。未改後端契約、schema、bot 或正式環境；未合入 main、推送或部署。先前功能驗收紀錄仍描述其固定提交，不代表本輪介面已完成視覺驗收。
