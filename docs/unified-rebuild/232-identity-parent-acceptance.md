## 線上資料隔離驗證

沿用 manifest `591a7209bf5ef07b3a79569a4abd411899660acfcf25b24ee1fb9e38098bbd7c` 的未修改匯入副本，不再擷取。原 web 來源 `83eb54ce94f935a4048aaf63a410206723f09bd8` 的身份／隱私函式作對照；Python 連線使用原服務的外鍵設定。只在原函式呼叫邊界固定時間及新隨機值，業務判斷不改。

- **2,186 次 HTTP**。48 個帳號的帳號清單／裝置與原 Python 一致，48 次成分關聯讀取保留原歸屬；讀取前後 **96 張表**的 rowid、值與儲存型別完全相同。公開讀取不新增會員。
- **48 次已有 QQ 身份重授權**，使用模擬 provider 回傳副本中的既有 subject。確認前不建帳號，確認後保留原站內稱呼、ID、成分及授權；重播與舊 cookie 拒絕，登出僅處理合成裝置，原其他裝置保全。沒有真實 QQ 授權。
- **68 份成分卡／原來源鍵查詢、24 組跨裝置流程**，逐組測確認、查看、一次接受、原帳號保持登入、明確切換、舊 scope 拒絕、當前裝置不可撤及撤權後原另一帳號仍可使用。五個無成分的看板帳號明確保存後各建立一份新成分，精確重試不重複，原 68 份成分歸屬不變。
- **48 個獨立註銷克隆**：42 個完成帳號註銷，原可變身份／session／管理／投票／圖片表與固定 Python 一致；其餘六個有未完成管理工作，拒絕且全部資料不變。共享狀態依目前實際保留資料核對；新系統額外保留的身份稽核及 bot 私人工作也納入待審判斷。
