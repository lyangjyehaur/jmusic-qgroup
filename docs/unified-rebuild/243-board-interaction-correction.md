# 看板交互修正

日期：2026-11-23。影響範圍：`web`；本次發布範圍：`none`，只更新本機預覽。

舊版以活動詳情串接本人報名、名單、分房、費用與管理。新版將這些操作拆成獨立頁面，未依本人狀態調整主要入口，並預先展開同行與付款設定；第 242 批的配色與連結分組沒有解決這個問題。

本批調整：

- 18 個既有活動子入口改用 Yahha Dialog；保留網址與原活動元件，關閉返回活動。直接開啟操作網址時不預先讀取或渲染額外的活動背景。私人查看邀請、認領、交接與補報名 token 入口仍獨立處理。
- 本人已報名時顯示狀態與管理入口，同行另有入口；報名受阻時顯示伺服器原因。名單可直接帶入本人／同行及確認、退出、退出申請處理等合法操作；權限仍由伺服器判定。
- 單人報名收起備註、同行設定與排隊選項；新增同行時展開必要欄位。保留預覽、逐人名額分配、費用約定接受與部分候補確認。成功取得結果、讀回最新資料並保存本機確認狀態後，才返回活動並更新名單；未知結果留在操作內，以原請求編號確認。
- 操作視窗不重複頁名或攤開完整安排與一串無關入口；費用規則保持可見，完整安排可展開核對。進階活動操作可展開，已結束活動預設展開費用入口。

驗證使用獨立 5083 合成預覽；5082 保持使用先前取得的最新正式隔離副本與工作資料庫。TypeScript、前端建置與 120 項前端／舊導航單元案例通過；原 90 個路由、LegacyLocalGuard 及私人 token 入口核對一致。另以瀏覽器驗證報名返回、原稿關閉／恢復、指定人員退出、未知結果重試及 360／768／1280 像素操作畫面，並回歸舊導航案例；最終 15 項瀏覽器案例全數通過（41.9 秒），已檢視手機與桌面操作截圖。

本輪沒有改 API 契約、資料庫、worker 或 bot 指令；舊 bot 網址持續映射到原功能。未合入 main、推送或部署。先前固定提交的驗收證據不自動適用於此次介面變更，尚未執行未受影響的全套端到端驗收。

2026-11-24 手機導覽調整：700 像素以下將主要導覽固定在底部，保留原入口與目前頁面狀態；內容、成分保存列與回到頂部按鈕預留導覽及安全區間距，保存列與導覽配合既有 visualViewport 位移。桌面仍使用頂部導覽。TypeScript 與前端建置通過，4 項相關瀏覽器案例通過，涵蓋手機／桌面、活動操作視窗及模擬鍵盤可視區縮小後的保存與原稿保留；已檢視手機截圖。影響範圍 `web`，發布範圍 `none`，只更新同一份本機工作資料庫的預覽。
