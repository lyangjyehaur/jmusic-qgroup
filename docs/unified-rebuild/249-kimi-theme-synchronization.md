# 全站主題色同步修正

日期：2026-11-25。發布範圍：`web`，僅前端色彩對應；沒有修改 API、bot、資料契約或正式環境。尚未提交、推送或部署。

## 原因與修正

先前外觀設定正確更新了 `data-preset` 和 Yahha 元件主題，但原型轉接層在淺色模式把 `--moss`、`--moss-dark`、`--moss-soft` 固定為苔綠，只有深色模式才將它們接到應用主題。導覽、連結、摘要、進度條等因此與按鈕分成兩套配色；氣泡、欄位焦點、通知及部分底色還含固定色碼。之前的按鈕對照不能證明整頁的配色一致。

現在所有明暗模式共用應用的強調色、深強調色及淡底色。`kimi/theme.css` 統一處理原型區域與 Yahha Portal 的動態顏色，包含導覽、摘要、連結、搜尋區、氣泡、進度條、已選狀態、儲存列、通知和對話框。原型來源 CSS 保留原檔；布局、元件形狀和業務操作未變。

紙面仍使用原型的中性底色，明暗模式獨立切換。成功、警告、錯誤及資訊使用語義狀態色，避免換成粉色時把報名成功也變成粉色。深色狀態色同時套用在 Portal，並調整強調色底上的文字對比。
