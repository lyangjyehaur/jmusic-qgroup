# 第七十六批實作：短效裝置連結與恢復

日期：2026-11-18（Asia/Taipei）。分支 `codex/unified-rebuild`。變更範圍 **`web`**，實際發布範圍 **`none`**。本機隔離開發與 mock QQ／兩個獨立瀏覽器 context 驗證，未合入 main、未部署、未操作正式資料或 bot 工作。

## 保存與恢復

發出與接收端改用獨立 IndexedDB `qgroup-device-links-v1`，保留原 bearer、捕獲時間及固定期限。`issued:<原 scope>` 分開各帳號，`received` 保留登入前訪客接收到的原連結。關閉全部分頁重開可恢復，但不保存同意勾選、不自動接受、不自動切帳號。接收端第一次保存的最長期限為十分鐘，取得服務端期限後只能縮短；重新載入不延長期限。

產生端 HTTP 前先保存無 token 的「結果待確認」標記。目的交易 abort 不發 HTTP，其他分頁不能從舊空快照產生競爭連結。回應與保存確認完成後才顯示 token；結果遺失或結果保存失敗仍留標記，先明確撤銷未使用連結再重新產生。晚回應／卸載後不顯示憑證，原標記供恢復；登出世代已改則不能寫回。

接收端保存交易成功才移除 fragment 與舊 session key。失敗保留原網址／分頁來源，不查詢也不接受授權；明確重新讀取能重新嘗試保存。已有不同連結時保留原紀錄，要求明確「改用目前開啟的連結」。登入仍返回原頁，接受仍保持原有帳號並明確切换。

## 到期、權限與清除

每次讀取清除已知到期 bearer；開頁定時器到期移除畫面及本機 token。瀏覽器完全關閉時無程式執行，下一次讀取才清除；服務端仍以自身十分鐘期限限制使用，不宣稱離線背景清除。損壞短效紀錄不加入版本庫，明確清除後重新開啟原連結。

產生、接受、撤銷及複製前核對 CAS／清除世代；產生／接受／撤銷另取得新 session 核對原帳號。接受成功後仍以原 session 綁定的 view 查回，不重複消耗。失去接受回應後關頁重開能看到原授權結果，原有會員不被切換；目前服務端期限以後仍需回帳號頁核對。

登出／帳號關閉清除這個獨立库並原子增加世代；即使 BroadcastChannel 不可用，舊頁也不能授權、複製或寫回。清除交易失敗時維持既有「已登出／刪除，但本機清除失敗」提示，保留原紀錄至明確重試，不重送已完成的伺服器操作。

短效 token 不進一般原稿／版本／收件匣索引、備份或網址 path/query。這是同源本機儲存，沒有宣稱加密或跨裝置同步；憑證與伺服器失效策略仍需實機／實際版本组合驗收。

## 驗證

未改裝置 API、schema、session／QQ identity 語意、通知、outbox、bot 指令或 bot 深連結。保留既有十分鐘一次性、雙端確認、只撤指定帳號、其他帳號授權及歷史分頁。

- strict TypeScript、React／API／bot build 通過；既有 bundle 大小警告仍存在。
- 短效紀錄／裝置 API、身份 bot、隱私、活動 bot 與管理 bot 原生回歸 **37 項通過**。
- 新持久化裝置 **13 項**、原裝置 **6 項**、原稿與刪除恢復交叉回歸 **24 項**、登入／隱私／管理隱私 **16 項**，共 **59 項瀏覽器場景通過**，無跳過。
- 建置後隔離 API、bounded room worker、bot HTTP／WebSocket／ACK／Resume／未知與模擬投遞、原生 runtime／停機及備份 smoke 通過，未啟動正式 worker 或真實 QQ 投遞。
- 360px 接受頁檢視通過，無水平溢出；雙裝置授權／明確切換／撤销與原成分保留回歸通過。
- 測試抓到遷移保存失敗後重新讀取未重新啟動保存，已修正；測試時鐘改在載入前安裝，測試確認碼／提示定位及登出後 fixture 重新登入已修正。

本批未處理原 `kanban-local-v1` 活動／投票／結算圖片／款項／pending requests。其 scope、原 payload、client_intent 與回執需透過同 origin client migrator 完整搬移，仍是下一批工作。跨裝置 create intent、完整恢復、實際平台與版本組合及切換／回退驗收尚未完成；166 項能力維持 in_progress、`release_eligible=false`，依使用者要求不部署。
