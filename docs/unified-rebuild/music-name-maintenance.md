# 詞條名稱與多語搜尋

2026-11-27。本機實作，未部署。發布範圍：`web (api + frontend)`。

## 維護與呈現

管理員的詞條建立／編輯加入「名稱與檢索」區塊：繁中譯名、簡中譯名、官方英文名、日文讀音、羅馬字及可逐項新增／移除的其他別名。原名、穩定詞條 ID、類型／分類、建立者、選擇與喜歡程度延續原資料。

前台詞庫列表、排行、快速加入、已選工作區、全站搜尋與詞條詳情呈現名稱資料。列表保留原名，僅補目前語言的中文譯名；其餘名稱在詳情按用途列出。簡中瀏覽器用簡中譯名，其餘用繁中。只填一種中文時轉換其字形作顯示與搜尋回退；不改寫儲存原文，也不代為翻譯日文。實際譯法不同可分別維護。沒有譯名時顯示原名。顯示回退由 API 產生，與可編輯欄位分開；前端只載入搜尋所需的繁轉簡字典，不載入完整簡轉繁字典。

所有名稱及舊別名均可搜尋；原名、別名完全吻合先於前綴、部分與發音匹配。保留舊中文拼音／首字母索引，新增簡繁、平片假名、NFKC、假名 Hepburn 讀音以及羅馬字大小寫、空格、分隔符與常見長音變體。日文漢字不猜讀音；依維護的假名、官方英文名或羅馬字補足。姓名的不同羅馬字順序可分別填在英文名與羅馬字／別名。

名稱欄位最多 96 個 Unicode 字元；其他別名最多 32 項。新名稱與別名會檢查其他詞條，含簡繁字形碰撞。舊資料中既有重疊別名保留，不因修改其他欄位被迫刪除。管理員改原名時舊名加入別名。合併保留目標的結構化欄位，把來源名稱移作別名；不變更既有選擇合併規則。

## 儲存、權限與相容性

沿用 schema v15 的 `music_documents` 擴充文件，`entry_names` 保存結構化名稱。完整 SQLite／配對備份保留這些資料；同時將可檢索名稱寫入既有 `aliases_json`，讓舊讀取者及舊格式匯出仍保留名稱字串。舊格式本身不保留譯名／讀音等欄位角色，不能把它當成結構化名稱的完整備份；完整恢復使用原生備份。

API 新增可選 `names` 欄位，既有詞條可沒有此欄位。省略名稱欄位的舊管理表單操作保留已存欄位；未添加名稱的詞條維持舊 revision，避免無關草稿衝突。名稱變更參與維護版本核對，並沿用管理權限、Origin／CSRF、冪等操作、配對備份與管理操作紀錄。一般會員不能提交結構化名稱。管理刪除、會員刪除、音樂清除與原生／舊版清除修復同步移除名稱文件，恢復邊界拒絕改寫原名稱關聯。

沒有修改資料表、schema 版本、outbox、QQ 設定、bot 路由或投遞語意；bot 不維護這些名稱文件。正式發布仍須驗證實際運行的 API／bot 組合；本輪不代表已完成正式發布驗收。新版前台名稱維護需要配套 API，不能只部署靜態前端。

已選用詞條的建立者修改限制尚未改動，等待確認「自己選過」或「其他人選用」作為鎖定觸發；本版不是該保護機制的完成宣稱。
