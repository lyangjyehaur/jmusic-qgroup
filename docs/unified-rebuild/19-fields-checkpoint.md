# 第十三批實作：獨立成分資料與欄位隱私

日期：2026-11-17（Asia/Taipei）。分支：`codex/unified-rebuild`。發布範圍 **`none`**；只修改隔離重構系統，未部署或操作正式 bot、資料與憑證。未來切換仍先按 **`both`** 準備，本批合成驗證不批准單邊發布。

## 欄位與入口

「我的成分」以「成分資料」開啟 `/me/music/details`，編輯獨立成分稱呼、性別／自訂性別、公開開關及私人留言。稱呼預設取建立當時的帳號稱呼，之後各自編輯；不改帳號、活動名冊、付款責任或歷史稱呼。管理成分查詢、關聯預覽、找回核對及會員成分卡改讀同一權威名稱。

變更後稱呼為 1–16 個 Unicode codepoint，正規化空白，拒絕空的名稱鍵與控制字元。重名依原版 NFKC、零寬／空白移除及完整 casefold 規則檢查所有有效成分；並行競態在 IMMEDIATE transaction 內檢查。不因既有來源的同名自動合併或搬移資料。

留言正規化空白，最多 140 字；清空將 `noteAt` 設為 0，內容改變才更新秒數。性別可不填、女／男或自訂至 12 字；自訂拒絕控制字元及尖括號。清除性別也清除公開開關。

編輯限制只套在實際更改的欄位。匯入原值、超過新限制的舊字串及小數秒不因編輯其他欄位而截斷、重排或改寫。已保存且未更改的舊不一致值仍保留，使用者明確編輯時才套用新限制。

## 可見性與資料生命週期

成分卡的性別僅本人或開啟公開的其他會員可讀。私人留言目前只由本人讀取與編輯，不包含在一般成分卡、QQ 查詢或管理成分搜尋回應中；**M18 尚未完整完成**。後續須連同匹配重建原版 `note_allowed` 與推薦排序／首名顯示的實際授權，不能把本批欄位編輯當作已還原他人留言可見性。

schema **8** 新增 `music_profile_fields` 與追加式 `music_field_history`，共 **83** 張使用者表（59 張相容表＋24 張重構／遷移表）。7→8 在單一交易內建立結構及投影有效成分：舊成分保留來源名稱與私有欄位；已存在的直接建立成分固定升級當時的帳號稱呼；刪除墓碑不投影。任一欄位型別錯誤或結構碰撞都回滾，不強轉型別或遺失來源證據。

欄位 revision 與選擇 revision 分開；改欄位仍提升總 profile revision，使舊選擇草稿必須先核對。新值、原／新私有歷史、總 revision、回執與成分回執索引同交易提交；任一寫入失敗全部回滾。無變更保存只記回執，不增版本或虛構歷史。

欄位修改不覆寫原匯入 JSON 證據；所有新讀取依權威欄位優先。重跑同一原快照不蓋回後來編輯。舊協議 adapter、完整 native archive 及回退匯出仍未啟用，切換前必須將權威欄位納入相應投影。

刪除成分清除欄位及其歷史、遮蔽舊私有回執；關聯移交亦使舊回執失效。epoch 阻止刪除重建、移交後再交回的舊草稿寫入。只關閉帳號保留獨立成分及其歷史，將該帳號涉及的欄位歷史列為共享資料待審。

## 草稿與錯誤恢復

草稿及待確認的精確 payload／UUID 依帳號 scope、成分 epoch 及 ID 隔離，留在本分頁 sessionStorage。送出前先保存；儲存失敗不送出，損壞原稿先保全。未保存或結果未知時離開有提示；更換帳號不套用其他帳號的草稿，刪除成分會清除跨分頁草稿。

斷線、不可解析成功回應、429／5xx 或成功後讀取目前資料失敗時，鎖定原操作並保留精確重試。回執確認後再讀最新值，不把舊成功內容覆蓋到後來版本。409 保留輸入，由使用者明確讀目前已保存內容與原稿對照，再決定保存，不自動覆寫。
