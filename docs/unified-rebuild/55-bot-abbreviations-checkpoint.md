## 已實作

`@qgroup/bot/abbreviations` 及獨立 `.rebuild-dist/bot/abbreviations.mjs` 提供原生 TypeScript 實作，不匯入或執行 Python。匯入不開網路、不讀寫業務資料或啟動輪詢；呼叫者明確提供結果目錄、查詢 adapter、遮罩規則及取消訊號。詞庫直接包含於獨立 bot bundle，沒有帶入網頁 bundle。

- **引用與英文擷取**：從 QQ 附帶的 quote elements 與 ref_msg_idx 選取原文，支援巢狀元素、未索引的文件範例與 malformed 輸入；不回查訊息歷史，不把未選中的其他消息當引用。明確指令優先，引用內的 `/退出` 等文字不會執行。移除網址、email、mention 與純數字後擷取完整英數 token，大小寫歸一、依原順序去重；超過五個仍保留到輸入驗證，要求縮小查詢，不暗中丟棄。
- **第三方查詢**：只送出正規化縮寫，無 QQ Authorization、cookie、聊天原文、群／發訊者身份。保留 2–32 位英數、最多五項與總輸入長度驗證，trans=null／空值／inputting 候選的差異、候選原順序、重複項目、完整長文字與程式／數學符號。上游連結及 mention 不轉發；只有普通文字，不產生 Markdown。
- **期限與快取**：單次整體網路期限預設 4 秒，持續慢串流不能延長期限；失敗冷卻 10 秒、新請求間隔 1 秒、每次只允許一個上游請求。不受取消的注入 adapter 仍占用 fetch slot 到實際結束，不能堆積 abandoned 工作；晚結果不寫快取。保留 1 小時 TTL、256 項 LRU、8 MiB 原始 JSON 總預算；超大單筆完整顯示但不快取。快取命中仍重新套用目前規則，失敗冷卻不阻擋有效快取。
- **完整遮罩**：64,578 條禁用詞、12 個允許表達與 4,113 個簡繁映射原樣保全，附原來源／固定 SHA／完整授權。逐字 NFKC、Python casefold、簡繁字形歸一與原字元 offset；稀疏 Aho–Corasick 只保留最長 suffix，合併重疊命中，允許表達只豁免完整包含的命中。候選組合後仍可跨候選遮罩，但保留「、」與換行；系統欄位邊界由 renderer 建立，候選自行插入冒號或換行不能偽造邊界。額外詞檔透過 `BotMaskLoader({extraFile})` 明確提供；檔案不存在、損壞或規則無效均拒絕未遮罩內容。預設資料與原始碼版本一起更新，額外詞檔在快取與續讀時檢查熱更新。
- **完整結果交付**：先嘗試完整回覆，只有明確長度拒絕 `40054007` 才依 UTF-8 bytes 縮小分段預算；每個普通被動訊息窗口最多五次請求，保留最後一次給續讀／失敗提示。event 回覆不拿相同 event_id 當普通分段窗口。除明確長度拒絕外，不自動重試未確認／拒絕的段落。續讀僅由使用者明確要求，顯示可能重複或未跳過失敗段落的提示，避免把不確定送達說成成功。
- **持久與重啟**：只把已遮罩的完整輸出保存在私有目錄，群只保存 SHA-256、token 為 24 位隨機 hex、有效期 1 小時；目錄 0700／檔案 0600，原子替換，拒絕 symlink、hardlink、跨群、路徑穿越、不合法 byte cursor 或欄位邊界。共享同一根目錄的實例在程序內序列化，最多 16 個待處理工作；發送時重新讀游標，舊快照不能重播已確認 prefix。規則更新先寫新 body，再原子發布 metadata，保留舊 body／cursor 到發布成功。新舊 Python 檔案與無 section_ends 的歷史格式均已互讀；不因此允許正式雙投遞者同時工作。

## 追加保全

每個分段發送前先持久化不確定游標；平台確認後才推進 offset。確認送出但游標寫入失敗時，不繼續自動分段，保留舊游標的待核對標記，提示「已確認送出，但續讀位置未能保存；續讀可能重複」。若連保全檔案都不可用，回報儲存失敗，不回傳未遮罩內容。

取消已開始的請求保留不確定結果，不再送第二次內容或續讀提示；進入隊列前／發送前的取消也會檢查。呼叫者可提供 `beforeSend`，在每次平台請求前重新驗群／設定；本函式庫不把這個擴充點宣稱為已完成的 runtime 群政策。

UTF-8 分段及欄位恢復也保留 BOM 與 supplementary scalar，不因 decoder 的預設 BOM 處理而遺漏文字或錯移 byte cursor。新輸出的欄位 metadata 與舊 Python 保持相容。

## 隔離驗證

新增 **2 檔／21 項測試**：輸入／quote 與 Python 實際函式差分、126 組遮罩／例外／重疊案例、完整規則與授權逐檔 SHA 核對、普通／候選完整輸出及欄位 byte ends 差分、64 KiB 以上結果、TTL／byte／256 項 LRU、快取與續讀重新遮罩、缺失／損壞規則、忙碌／限流／失敗冷卻、慢串流期限／晚結果／取消及只傳縮寫的本機 HTTP 檢查。

投遞另以 **9 組實際 Python 差分**比對全部平台呼叫、seq、普通／event 識別、結果、完整待讀 body、游標、預算與 metadata；其他案例驗證多窗口／重啟交付、emoji／BOM、動態縮小預算、失敗／不確定不自動重送、規則更新及原子發布失敗、確認後 cursor 保存失敗、跨群／過期／symlink／檔案權限／邊界損壞、舊快照並發，以及新舊 Python 檔案雙向互讀。網路只有合成本機 HTTP 或 adapter，沒有查詢真實上游或 QQ。

額外離線逐詞比對全部 **64,578** 條 bundled 禁用詞：依原順序對每個原詞呼叫 mask，將每筆輸出加 LF 後串接 UTF-8 SHA-256；新 TS 與保留 Python 均為 `a085176a38b19d8afd24b66bc132a665e3fa1441193d66bc3f72fe19b0eeb8bf`。這證明本版本對既有詞表的單詞輸出一致，不宣稱涵蓋所有語境、異體或未來 Unicode 行為。

built smoke 在 fetch／WebSocket 被禁止、空工作目錄下匯入四份 bot bundle，驗證沒有副作用；之後顯式以合成 adapter 驗證完整預設遮罩、查詢快取不重打上游、真實 byte 分段與跨實例續讀完整重組。既有 transport／outbox／public replies／網站／分房／備份／恢復 smoke 保留。

本批未修改前端畫面、操作或導覽，沒有重跑無關瀏覽器流程。完整重構回歸 **84 檔／668 項通過**；保留 Python bot **311 項**與時間投票 bot **15 項**通過。strict TypeScript、重構建置、built smoke、既有 UI 產物、capability ledger 與 diff check 通過。獨立 abbreviation bundle 約 **2.8 MiB**（含完整詞庫），前端主 JS 維持約 **1,152.94 kB／gzip 336.99 kB**；完整詞庫的建庫／重新遮罩 CPU 與正式規模記憶體仍須 runtime 隔離和效能驗收，不能以網路 async 或本機 smoke 代替。
