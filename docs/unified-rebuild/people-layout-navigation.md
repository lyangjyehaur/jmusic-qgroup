# 同好頁版面與動線調整

發布範圍：`web`（`frontend`）。本次只完成本機預覽，未推送或部署。

## 調整

- 推薦、查詢／比較、同好圈子及找搭子共用頁首與四個分頁；移除重複的跨頁入口，保留成分編輯與自由分房。
- 推薦卡優先顯示姓名、匹配度和共同詞條，詞條與 44px 選取控制水平排列；完整成分、聯絡及複製功能放入更多資料。資料較少的名單不再重複展示。原排序、前三位推薦與完整名單仍保留。
- 查詢使用 Yahha 欄位與操作按鈕，編輯時清除過期錯誤；成分卡、比較及詞條保留安全的返回來源，返回查詢時維持分頁和排序網址。
- 圈子統計採共用概覽樣式；成員可展開完整名單，常見詞條保留各自入口。圈子門檻、同名詞條和未連入圈子的資料仍保留。
- 找搭子先呈現名單，桌面並排發布表單，手機提供跳至發布的按鈕。保留歷史、分頁、發布冷卻、原稿恢復及未知提交結果的確認流程。
- 成分卡修正資料欄被通用定義清單擠成逐字換行、完整成分被三欄樣式壓縮的問題；比較詞條統一為可讀的整行清單。
- 修正手機找搭子名單和表單落在同一格而重疊，以及舊卡片外距累加。深色與緊湊模式使用既有主題設定。

## 驗證

- `npm run build:frontend` 通過，包含 HTTP 契約檢查、產物生成與 TypeScript 型別檢查；僅有既有 Vite 分塊提示。
- 初次驗證圈子、共用導航、Yahha 控制及相關功能；最終修改後重新執行 `music-matches.spec.ts`、`music-shouts.spec.ts`、`music-level-picker.spec.ts`，28 項通過；最後補上舊時間戳邊界保護後，找搭子 9 項再次通過，共 29 項相關回歸。保留帳號切換、隱私抹除、過期讀取、跨頁原稿及未知發布結果等回歸覆蓋。
- 真實資料效果驗收使用 2026-11-27 09:16:03（臺北時間）擷取的正式一致性副本：18 個活動、106 筆報名、56 個帳號、153 個詞條；保留既有本機測試編輯與本機登入。
- 私人驗收在 320／430／749／1440px 檢查四個分頁、橫向溢出、44px 詞條控制、查詢與比較返回來源、成分卡可讀性、找搭子區塊不重疊、圈子完整成員、深色及密度。兩項驗收通過；緊湊模式詞條行高由 55px 降至 49px，已保存成分未變。
- 使用者瀏覽器已核對登入及實際推薦、圈子、找搭子和成分卡，最後停留在 `/people`。

## 相容性與本機測試範圍

本次不修改 API、資料契約、schema、outbox、bot 或既有深連結入口；只有返回網址附加既有支援的 `from` 查詢參數。沒有進行正式服務的版本組合發布驗證，不以本機結果宣稱已上線。

本機 5189 的副本停用正式憑證、bot 及外部投遞。查詢／比較的唯讀 POST 已開放；詞條維護、成分選取及找搭子發布只寫本機副本。活動及帳號修改、詞條刪除／合併仍受測試服務限制。資料庫、登入憑證和驗收截圖只存放於忽略版控的私人目錄。
