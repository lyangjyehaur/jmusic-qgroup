# 第五十四批實作：合作方原生 API v1

日期：2026-11-18（Asia/Taipei）。分支 `codex/unified-rebuild`。本批程式影響範圍 **`web`**；實際發布範圍 **`none`**：只做本機隔離實作，未合入 main、未部署，未使用正式金鑰、會員資料、群設定或待送工作。Python bot 保留；schema 維持 **14／94 張表**。

## 保留合作方契約

原生 Fastify 獨立註冊 `/api/public/v1` 與其子路徑，提供索引、活動分頁／篩選、單場詳情、逐人名冊及預分／實際包間。沿用 `KANBAN_PUBLIC_API_KEYS`、原始 snake_case 欄位、16 位小寫十六進位活動 ID、相對活動網址及既有錯誤格式；沒有呼叫 Python 或瀏覽器 serializer。

每次請求先檢查設定及 Bearer，再處理方法與資料；缺少／錯誤金鑰為 401，空白／格式錯誤設定為 503。從原始 header 行檢查重複 Authorization，逐把雜湊固定時間比對；最多 20 把與輪替／撤銷語意不變。OPTIONS 不需金鑰且不開 CORS；有效金鑰的寫入方法為 405，GET／HEAD 的 Allow、no-store、無 Cookie 與 HEAD 空 body 保留。這組唯讀路徑不套用瀏覽器新增的 GET 限流。

參數直接取原始 query，拒絕未知、重複、空值及超界數值；不因 Fastify 的 query 解析或第二個 `?` 而吞掉輸入。公開篩選僅接受已發布、非刪除且 visibility=public 的活動；取消、結束及歸檔仍可同步。登入 Cookie、管理員身分或持邀請帳號不擴大權限，Accept-Language 不改變契約與使用者原文。

## 名冊、包間與唯讀保全

名冊僅含 confirmed／waiting／tentative，沿用 party.seq／attendee.seq 後按狀態穩定分組。`user_id` 來自本人已認領的報名關聯，未認領同行不使用 manager_id；註銷記錄存在時一律解除公開帳號連結。跨活動保留同一帳號 ID，認領保留原 attendee_id。

預分使用當前有效人員與最新預分版本，排除舊快照中的邀請／退出者；未分配清單沿用原報名順序。實際包間只取最新已發布結算的詳細快照，保留凍結姓名及後來退出的人；帳號關聯仍依目前報名與註銷狀態投影。無包間欄位或空陣列的詳細結算提供空實際包間，不回退成預分；最新人均舊結算則 actual=null。付款人、金額、憑證、備註及原始快照均不輸出。

檔案資料庫在通過鑑權後另開 `readonly + fileMustExist + query_only` 連線，每次回應在同一 SQLite 讀取交易取快照，忙碌等待上限 100ms；不建立檔案、不遷移、不建立 session。隔離記憶體庫同步使用原連線並在成功／失敗後恢復原 query_only，沒有跨 await 持有暫時狀態。

刪除 journal 未完成時，合作方請求只檢查可讀狀態並回 503，不執行寫入式恢復，也不輸出恢復前資料。網站原有恢復流程完成後才重新提供安全投影。恢復候選、缺檔及損壞快照回通用 503；這是新版暫時不可用處理，不冒充活動不存在。日誌沿用全 query 遮罩與 Authorization 隱藏，內部失敗不記錄 SQL、路徑、快照或錯誤原文。
