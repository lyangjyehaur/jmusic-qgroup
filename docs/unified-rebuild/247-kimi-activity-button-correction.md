## 修正

- 活動列表直接使用原型 `Button` 與 `CalendarPlus(17)`，文案恢復「新增活動」。按鈕透過 React Router 進入原有 `/activities/new`，保留路由阻擋與草稿→核對→發布流程。
- 淺色粉／藍／黃採原型使用的 Yahha 原生主題，苔綠採原型的公開 token 覆寫；深色仍使用已授權的深色延伸。
- 移除額外的細邊、soft 圓角和按鈕陰影覆寫，恢復原型元件的實際輪廓與配色。
- 移除與原型相反的手機頁首排列覆寫，恢復靠右操作列；手機頁面上方間距恢復 22px。
- 同步更新使用說明中的活動頁入口文案。

沒有把原型 Link 包 button 的巢狀互動元素搬入正式介面；使用真正的按鈕與既有導覽處理。既有後端草稿規則沒有改成原型模擬的直接發布。
