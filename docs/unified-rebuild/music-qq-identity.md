# 成分名稱、QQ 與頭像整合

發布範圍：`web`（frontend + api）。本次只完成本機修改與驗收，尚未推送或正式部署。

一般介面使用成分名稱與 QQ 辨識同好，不再用內部成分 ID 補位。涵蓋同好推薦、成分卡、詞條選取者、趨勢、找搭子、我的頁面、成分資料、管理員成分目錄及刪除預覽。查詢入口以 QQ 標示，分房定位也不再把內部 ID 填入搜尋框；同名成員仍以定位結果的 ID 精確篩選。既有 ID、QQ 與匯入查詢別名的 API 解析、網址和返回來源保持有效。

QQ 仍選填，未填時在同好推薦、我的與成分編輯／資料頁提供填寫入口；不影響登入或保存詞條。移除一般介面的「舊成分」「未經騰訊驗證」來源標籤，找回入口統一稱為「找回成分」。未認領成分仍需原口令與本次 QQ 授權核對，沒有新增另一套帳號，也不憑名稱或自填 QQ 合併成分。原本僅可由管理員更正的 QQ 保留限制，提示改為「此 QQ 僅由管理員更正」。

會員成分 API 新增可選 `avatarUrl`。只讀取目前 QQ 應用下、有效成分帳號的 `external_identities` 與 `external_profiles`，並通過既有 `safeAvatar` 驗證；未綁定、已撤銷、已刪除或不安全的圖片地址不提供頭像，以名稱首字回退。同好、成分卡、圈子、選取者、趨勢與找搭子沿用 Yahha UI Avatar。活動名冊也承接既有僅讀 QQ profile client 設定，預覽停用 OAuth 時仍可展示副本中的頭像。

頭像在既有權限檢查後加入回應，圈子在 worker 結果重新授權後加入，不進入計算輸入。公開趨勢仍只有彙總。分享圖片移除內部 ID 和來源警告，QQ 維持個別勾選；圖片不載入外部頭像，避免跨來源 canvas 或額外匯出聯絡資訊。

未變更 schema、帳號主鍵、登入、outbox、群設定或 bot 指令。可選讀取欄位兼容原回應；正式發布需要更新 API 和前端，不能只替換前端來取得新增頭像。正式發布前仍須依發布政策核對實際 web／bot 版本組合。

驗證使用 2026-11-27 09:16:03（臺北時間）擷取的正式一致性副本：18 個活動、106 筆報名、56 個帳號，153 個詞條。副本及圖片只保留在忽略版控的私人目錄；保留本機登入及既有本機編輯，沒有正式寫入、bot 或外部投遞。

驗證結果：

- 前端建置、TypeScript 與 218 項 HTTP 契約／權限來源核對通過。
- 109 項不同的 API 回歸測試通過，涵蓋聯絡 QQ、匹配、圈子、找搭子、趨勢、詞條、成分資料、分房、成分管理／刪除及活動名冊。新增頭像驗收覆蓋 QQ 應用隔離、URL 驗證、撤銷／刪除、匿名拒絕、公開彙總與圈子資訊限制。
- 76 項不同的瀏覽器回歸通過，涵蓋保存、衝突、草稿、清空 QQ、複製、查詢與返回、分房定位、分享、找回、撤銷及刪除。已更新相關文字與網址預期，失敗案例修正後單獨重跑通過。
- 真實副本在 320／430／749／1440 px 核對 QQ 查詢、已載入頭像、長 ID 移除、選填引導與頁面不溢出；保留四分頁動線、圈子完整成員、深色及密度切換驗收。
