# 「我的」頁面整理

發布範圍：`web`（`frontend`）。本次僅完成本機修改與驗證，尚未整合 main 或正式部署。開發分支為 `codex/me-layout-20261128`，基底為 main 的 `df14ca635c8381ebb93050397eeff4d77e8a3b07`。

## 頁面與動線

- 主入口改為「總覽／活動草稿／設定」。總覽顯示本人資料、成分與活動數字、近期活動、參與統計和常用功能，移除重複的設定入口與「更多設定」折疊。
- 設定依「帳號與資料／偏好與隱私」分組；帳號、稱呼、裝置、收款碼、外觀、應用程式和資料刪除均保留原網址。舊的 `?tab=account|privacy|danger` 顯示完整設定入口。
- 設定子頁省略總覽資料卡與數字。桌面使用左側設定導覽，較窄畫面使用「全部設定」返回連結；既有表單、返回原任務、帳號切換、登入／登出和草稿保護維持原流程。
- 近期活動顯示日期、開始與結束時間、地點與報名狀態；跨日時間沿用活動列表的格式。草稿集中於草稿頁，依編輯權限顯示操作並保留完整草稿列表入口，時間改為瀏覽器時區的可讀日期。
- 使用共用 Yahha UI 分頁、按鈕與原型色彩。卡片、標題／操作排列、手機數字對齊、設定列、表單欄寬及深色／緊湊模式一併整理。
