## 測試、失敗證據與限制

本批 **159 個單元、46 個瀏覽器案例**通過，零略過／重試／flaky；另沿用同一不可變原 bot 映像的 **117 個原 Python 案例**，原測試 blobs、映像 ID 及成功報告重新核對。943 個目前來源／測試與 245 個本機產物未變。新映像的網站 runtime／來源／靜態產物、健康／版本及離線 Compose 身份檢查另通過；後者只是 metadata 檢查，不是發布保障或 Python 組合功能證據。

所有執行容器使用 network none、唯讀 rootfs、UID 994／GID 992、512 MiB 且無額外 swap、1 CPU、128 PID、64 MiB tmpfs。原整合 bot 煙霧程式同時載入全部 library 並啟動 bot 子程序，5 秒觀察逾時；加入時序診斷後另記錄到 OOM。將原 library 斷言與原入口斷言分置容器後，library 無 OOM 通過；入口仍超過五秒觀察，30 秒有界觀察取得 **7,743 ms** 首筆確認及正常停止／鎖釋放／stopped 健康。這是 Mac 上 amd64 模擬執行的實測；沒有改動產品時限、投遞時鐘或資源上限，也不聲稱原五秒整組已通過。

首次建置未指定與原 bot 相同的 amd64，已中止並保留日誌，正確架構的新建置通過。私人唯讀 helper 初次使用本機 Python 不提供的 SQLite serialize，第二次過早禁止 socket 影響 SSL import；修正 helper 後完整雙來源比對通過，產品與原 oracle 未改。
