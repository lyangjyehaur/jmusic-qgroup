# 草稿變動判定

發布範圍：`web`（`frontend`）。本次僅在本機修改與驗證，未部署。API、資料庫、outbox、bot 與網址契約不變。

## 判定規則

- 以目前可編輯內容與保存／表單初始內容比較。改回原值後，保存浮層、恢復提示與離開警告消失。
- 詞條選擇比較詞條 ID 與喜歡程度，忽略取消後重新加入造成的陣列順序差異；程度不同仍是實際修改。
- 物件欄位順序不影響比較。包間、費用項目等有順序的陣列仍比較順序，沒有全站排序所有陣列。
- 投票、包間及結算表單保存初始內容基準。生成的操作 UUID、初始費用項目 ID 與時間不會在每次編輯時重新生成基準。
- bot 設定、詞條編輯、壁紙間隔及帳本表單改回原值後保持乾淨。分房試算比較實際初始名單，包含自己及活動預選名單；已產生的試算與人工安排仍保留。
- 稱呼、成分資料、聯絡 QQ、管理備註等不因版本號單獨不同而宣稱有使用者修改；載入相同內容且沒有待確認操作時更新到目前版本。
- 不把等待本機保存的乾淨記錄當成離開警告。真正修改、保存錯誤及進行中的提交仍需處理。

## 原稿與操作保全

本機記錄新增可選的 `baseline`／`baselineSelected`，保留舊記錄讀取、匯入、下載及版本恢復。舊的損壞記錄、不能證明相同的原稿與來源資料仍需顯式恢復或捨棄。只重設已確認沒有內容差異的記錄。

待確認操作獨立於內容差異：即使內容與保存版本相同，仍保留原請求 UUID／payload，不自動重送或清除。刪除、合併、恢復前版等已選定的管理操作也保留原有確認流程。跨分頁衝突、失效隔離、帳號範圍與刪除柵欄繼續生效。

## 驗證

- 回歸包含領域／細分取消再選回、程度改回、舊順序草稿、待確認相同操作、投票改回、表單文字與開關改回、分房預選名單、管理詞條／bot／壁紙／帳本表單、稱呼與 QQ、重新開頁及離開。
- 另外檢查既有原稿恢復、費用與結算、跨分頁、登出／刪除隔離和原 UUID 重試。
- 效果驗收使用 2026-11-27 09:16:03（台北）擷取的正式資料一致性副本：18 活動、106 報名、56 使用者；在獨立本機瀏覽器以實際 20 詞條成分核對 430／873 寬度。驗收 API 寫入為 0，待確認操作保留；測試資料與圖片只存於忽略版控的私人目錄。

另有兩項時間投票列表的舊佈局斷言要求分頁列沒有水平捲動，於 789／390 寬度未通過。已在此次修改前的 `ab65107fa59dceb8ab2cbc2f133b814bc53ca138` 獨立建置中重現：分頁列寬度分別為 537/445、521/358，整頁沒有水平溢出。此項與草稿判定無關，本次沒有修改該版面或放寬測試。

最終驗證：全站相關表單回歸 91 項通過；包間／結算及本次變動回歸 24 項通過（兩組有重疊）；比較工具單元測試 3 項通過；正式資料副本效果驗收 1 項通過。TypeScript、HTTP 契約檢查與前端建置通過。
