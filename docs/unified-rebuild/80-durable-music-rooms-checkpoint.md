# 第七十四批實作：自由／活動分房原稿持久化

日期：2026-11-18（Asia/Taipei）。分支 `codex/unified-rebuild`。變更範圍 **`web`**，實際發布範圍 **`none`**。本機隔離實作，未合入 main、未部署，未接觸正式資料、憑證、群設定或真實 bot 工作。

## 同一分房原稿與上下文

自由分房與活動試算改用共用 IndexedDB，保存來源快照、原選取次序、房數／容量／自訂人數、公開性別偏好、人工移房與未安排人員、分析及分房結果。關頁重開保留原文；有實際內容的原稿需明確恢復，恢復或載入保全版本不會自動計算、分享或正式採用。編輯中的不合法容量仍保存，正式計算繼續經嚴格 command 驗證。

新 key 為 `qgroup:rebuild:music:room-lab:v2:<scope>:<musicEpoch>:free` 或 `...:event:<canonical 編碼活動 ID>`，區別帳號、成分世代、自由與活動來源；活動 ID `free` 不再與自由試算衝突。來源回應必須對應目前活動；保存原稿也須對應原活動。非 canonical 編碼、非法世代及跨帳號 key 不接受。

舊 `qgroup:rebuild:room-lab:v1:<scope>:<eventId 或 free>` 原文在目的交易提交後才移除；匯入失敗保留來源，目的已有不同原稿則保全版本。舊 key 的自由／活動 `free` 碰撞以原文的明確 eventId 分辨，不能將可識別的另一上下文移走。無法辨識的原稿仍可先保全下載再建立新試算。

## 交易、競爭與來源更新

試算與定位成員前等待目前原稿整筆交易提交；結果也在保存成功後才顯示，結果確認失敗保留原安排。這些是唯讀試算，不建立業務 pending 命令或新增通用回執。試算回應須符合原 sourceVersion 與選取次序；重新計分還須符合原包間 ID／容量／人員，避免不相符結果覆蓋目前安排。

共用 CAS 保全競爭原稿與晚到的結果，不覆寫已保存的新輸入；載入已保存版本或保全版本不觸發試算。保存失敗時離開會重新等待保存，仍失敗就留在原頁。試算執行中可明確取消等待並保留輸入離開；切活動、切帳號及卸載後不採用晚回應。

背景來源更新不覆寫原稿；舊結果、分享與正式採用失效。明確核對新來源時，先保全原快照和人工安排，再保存新來源、移除已無成分的選取並清空結果；原房間輸入保留，需重新計分。來源失敗仍保留原稿，權限拒絕則隱藏私人名單與結果。

## 分享、採用與清除

產生／重試圖片、轉檔完成、複製、下載或分享前重新經原稿交易檢查清除世代；本輪補上無 BroadcastChannel 的刪除／登出測試，舊頁不能再試算、正式採用或複製已生成圖片的清單。成分清除會原子移除這個音樂原稿與保全版本，舊頁不能寫回。圖片仍須重新確認分享範圍；白名單、完整文字退路、原生分享失敗下載、圖片重試及 360px 長名行為保留。

正式採用仍先進既有預分編輯頁核對。原稿保存成功才導頁；已有正式編輯原稿仍需明確確認替換，保留房間 ID／名稱／付款人，再確認保存。試算與採用預覽不記帳、不產生群通知。

## Bot、資料與驗證

未改 API、schema、演算法、正式包間保存、設定、通知或 outbox 契約。既有原生分房測試覆蓋實際 Python 差分、worker 限制、來源再驗、正式保存回執、實際 Python 包間與 bot 讀取，以及所有 pending／sending／sent／failed／skipped、模擬／未確認投遞與 bot 政策紀錄不變；均為隔離 fixture／本機模擬，未宣稱真實 QQ 或實際線上版本組合已驗收。

- 嚴格型別檢查與 `npm run build:rebuild` 通過；既有 bundle 大小警告仍存在。
