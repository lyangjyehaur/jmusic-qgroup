## 統一外觀

「我的 → 外觀」提供淺色、深色、跟隨系統與個人壁紙開關。設定套用至活動、音樂、同好、帳號及管理頁；在 React 啟動前套用主題，路由切換不重設。CSS 使用同一組文字、背景、邊線、表單、狀態及焦點色，Yahha 控制項與 portal 沿用相同 tokens；原生名冊成分對話框與趨勢圖也支援深色。

偏好只保存在瀏覽器，不以會員身份同步；讀取舊 `jpm.theme`／`jpm.wall`，保留明確停用，不再於啟動時強制開啟壁紙。新版採有版本的 `qgroup:appearance:v1`，跨分頁 storage 事件同步；保存失敗時本次設定仍有效並提示重試，損壞原稿必須先保存恢復副本才覆寫。

壁紙在圖片 fetch 與完整瀏覽器解碼完成後才換入，保留前後兩層做漸變，隨機選圖且避免連續重複；橫直圖與視窗方向不合時採完整顯示。減少動態效果時保留單張，分頁進入背景時停止排程；載入或解碼失敗時嘗試其他圖片。離開／停用／配置變更會取消請求、移除監聽及計時器並釋放 object URLs。背景遮罩配合主題，保持正文對比。管理變更透過 query invalidation、跨分頁通知及取得焦點重新讀取設定。

## 原生管理流程

「管理後台 → 壁紙管理」提供原圖預覽、上傳、刪除、啟停、上下排序與 8–600 秒輪播間隔。讀取來源缺圖或瀏覽器無法解碼時顯示具體恢復提示，保留原紀錄；刪除明示公開連結及圖片會移除。帳號管理員無須先建立成分，獨立救援管理也可使用。

支援 PNG／JPEG／WebP，單張最多 2 MiB。API 同時核對嚴格 base64、實際位元組數、宣告 MIME 與完整 raster 解碼；使用固定版本 `sharp@0.35.5`，限制 4000 萬像素，拒絕 SVG、格式偽裝、破損與超限圖片。保留接受的原始 bytes，不在伺服器靜默轉碼；上傳處明示原圖會公開。新的 API 不依賴 Python 圖片處理執行環境。

每筆管理操作必須重新核對目前角色／救援授權、Origin、帳號 scope、一般與管理 CSRF、明確確認、UUID 與完整設定 revision。圖片解碼在 writer transaction 外進行，完成後再次核對授權與版本才寫入；圖片處理途中撤權也會拒絕。revision 過期時保留輸入，要求明確核對最新版與重新確認。

瀏覽器先保存精確 body、原圖與 UUID 再提交。未知結果只能以原 UUID／body 查回，重整後仍保留；同一張圖只存一份 base64，避免回執造成雙倍儲存需求。儲存失敗不提交，提供重試；若伺服器已保存但本機清理回執失敗，明示已完成、保留原操作，恢復儲存後可取回同一結果。原稿損壞先保全，離頁有保留草稿提示。撤權、切換帳號或卸載後，晚回應不能恢復管理畫面。

## 資料、遷移與相容性

schema 13 新增 `wallpaper_assets`、`wallpaper_items`、`wallpaper_config`、`appearance_actions`。圖片 BLOB 依 SHA-256 去重，清單保存固定 ID、舊來源、名稱、啟停與順序；配置與原始 manifest 一同保存。資產、清單、輪播設定、追加管理稽核與精確操作回執在同一筆 SQLite 交易提交；最後引用刪除才移除資產，失敗整體回滾。管理稽核納入帳號隱私的共用紀錄審核。

12→13 遷移從隔離庫同層 `walls/` 一次匯入；成套快照匯入在同一筆投影交易載入來源素材。沒有來源時保持未初始化，允許之後顯式匯入；匯入成功後不再從舊 manifest 覆蓋管理變更。保存原始 manifest 額外欄位、原圖 bytes、停用及缺圖清單；舊素材以保全為先，不以新上傳限制丟棄歷史檔。路徑只允許安全檔名與 raster 副檔名，禁止 traversal 與 symlink，單一來源檔上限 32 MiB。來源異常或 DDL collision 回滾本次遷移。原始 `walls/` 仍作匯入原件保全，SQLite 為新版壁紙的權威來源。

公開 API 只回傳啟用且具資產的項目，圖片下載再次核對 digest／raster 簽名，`no-store`／`nosniff`；舊 `/walls/:file` 與 `/music/walls/:file` 圖片連結保持可讀。舊管理／manifest API 轉接與完整回退輸出仍待後續相容工作，不能用此批宣告全部舊入口驗收完成。

59 張既有相容表、Python bot、outbox、群設定與通知網址沒有修改。遷移前後保留原表 DDL／資料，並直接執行既有 Python `accounts`、`identity`、`bot_views` 讀取，比對身份、活動、名冊與待送狀態；管理變更也核對 bot 表未改。沒有使用正式資料、QQ 憑證、真實群聊或投遞者。
