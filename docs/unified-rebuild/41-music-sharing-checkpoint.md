# 第三十五批實作：成分分享與清單複製

日期：2026-11-17（Asia/Taipei）。分支 `codex/unified-rebuild`。發布範圍 **`none`**：本機實作、隔離驗證與原始碼同步，不部署、不整合 main。運行產物候選範圍為 `web`，新增分享讀取 API、原生 TS Canvas 與 TSX 頁面，未改 schema、Python bot、outbox、群設定或既有 bot 深連結；正式版本組合仍待成套驗收。

## 草稿、分享與返回

新增 `/me/music/share`，與詞庫、詞條、我的成分共用同一個 `MusicWorkspace`。選擇面板提供「分享成分」，帶入原搜尋與返回參數；分享不觸發離開工作區確認，不建立第二份草稿，也不自動保存選擇。從分享回去仍保留原順序、細分程度與未保存操作。離開整個工作區仍按既有規則確認，沒有為分享繞過草稿保全。

對照舊 `drawShareCard`／`copySelection`／`nativeShare` 的實際行為：分享與複製使用目前選擇，包含尚未保存的草稿；推薦同好按最後保存的成分計算。頁內及圖片明確區分草稿與已保存，草稿提示說明推薦資料來源。第一次尚未建立成分亦可分享目前選擇，顯示帳號稱呼，不捏造固定 ID 或自動建立成分。空選擇提供返回入口；損壞草稿及保存結果待確認時先引導回原操作，不拿 fallback 內容冒充原稿匯出。

文字清單保留來源選擇順序與「、」分隔，不附加稱呼、帳號、聯絡號碼、留言或程度。已移除的詞條與原來源一樣不納入匯出，頁內告知數量，原草稿不被清掉。只讀 textarea 保留完整文字供手動複製；Clipboard API 缺失或拒絕時有具體退路。

## 原生圖片與裝置分享

以新的型別化繪圖服務產生 PNG，沒有匯入舊 DOM controller／HTML 或外部圖片，也沒有新增圖片上傳。保留領域／細分、細分程度、人數、名稱、固定 ID、推薦同好的名稱／ID、匹配度與共同項數，以及網站詞庫入口。淺／深配色可選；不帶舊裝飾口號、品牌理念或填空用頁尾。

圖片寬度 720 邏輯像素、以二倍解析度輸出，按內容決定高度，完整保留最多五領域與十五細分。名稱按 grapheme 換行，詞條最多三行、稱呼最多兩行後才省略；不拆 emoji、補充平面或組合字。原完整詞條名稱仍保留於下方清單與複製結果。長詞條、資訊副行與推薦區依實測文字高度排版，避免原版截短 UTF-16 或名稱／人數互相覆蓋。

圖片預覽與下載使用本機 object URL，原生分享使用已產生的同一份 PNG File，避免按鈕點擊後先等網路／轉檔而遺失 user activation。瀏覽器不支援 `canShare`／`share`、檢查拋錯或分享失敗時改為下載；使用者 `AbortError` 取消時只顯示取消，不沿用原版「取消也下載」的意外行為。Canvas、toBlob 或圖片解碼失敗可重試，文字清單仍可用；讀取分享資料失敗會移除舊預覽，保留目前詞條複製與重新讀取。

瀏覽器實際解碼測試揭露原 CSP 不允許 blob 預覽：原 PNG 可下載但圖片寬度為零。僅在 `img-src` 加入 `blob:`，script／connect／object 來源維持原限制；API 測試核對政策範圍，瀏覽器驗證真實 PNG 解碼、1440px 寬度、深色像素與下載內容，不能只憑 img 存在就算預覽通過。

每次內容／配色更新會替換並撤銷舊 object URL，離開頁面也撤銷；晚完成的轉檔不再建立 URL。帳號切換、登出、刪除及 metadata 失效會清除舊預覽，已失效的原生分享 Promise 不得觸發晚來的下載退路。這些行為無法撤回使用者先前已自行下載、複製或交給裝置分享的檔案。

## 匯出資料與排序偏好

新增 scoped `GET /api/v2/me/music/share?sort=rare|familiar`，只回傳本人成分 ID、musicEpoch、稱呼、目前聯絡資料、排序，以及主榜第一位同好的最小資料與兩個匹配指標。使用 session 身份，拒絕 target／viewer 額外欄位；讀取在同一 SQLite 交易快照完成。未建立成分回傳本人帳號稱呼與空聯絡／推薦，資料較少分區不冒充主榜推薦。

回應從伺服器明確白名單組成，不回傳任何私人留言、性別、PIN 摘要、帳號關聯鍵或憑證，不以圖片繪製時「沒用到」代替 API 保護。名稱／聯絡依現有原生欄位及 canonical contact 優先規則，原別名、解除關聯或已刪資料不被誤用。圖片預設保留推薦區；本人的聯絡 QQ 與同好的聯絡 QQ 各自明確勾選、預設不包含。與舊版無條件畫出號碼的差異在操作前提示；需要原先完整內容時仍可選擇包含。輸出號碼標為未經騰訊驗證，不當成身份認證。

前批推薦 URL 已保留排序，本批另補回來源 `jpm.matchSort` 的本機偏好語意：推薦及分享共用同一 hook；明確 URL 優先，無參數時讀新版偏好，缺少新版值時可沿用同 origin 的舊偏好。操作寫新版偏好並更新 URL，不改來源偏好；localStorage 被禁用時當頁與 URL 仍正常，不阻擋分享。正式跨 origin／瀏覽器設定完整遷移仍是後續 client migrator 的驗收範圍。

私人 query 以 scope、musicEpoch、sort 分鍵，進入時等候新回應並定時／focus 更新；本頁成分保存、稱呼／留言／性別與聯絡修改會使分享查詢失效，跨分頁沿用統一帳號通道。沒有使用持久快取儲存 PNG 或額外蒐集分享紀錄。API 沿用 `no-store`／`Vary: Cookie`，全資料表與 `total_changes()` 證明分享讀取不寫活動、財務、bot 或成分資料。

## 驗證與限制

新增三項 domain 測試：擷取實際舊 `copySelection` 進行一至二十項選擇／未知詞條差分，匯出欄位白名單，完整長名與 grapheme／行數邊界。新增五項 API 測試：兩種保存推薦、native／legacy 名稱及聯絡優先、首個成分草稿、scope／session／查詢限制、刪除／重指派／epoch、私有欄位不出站、CSP 限定及全表快照／總寫入數不變。後端／領域全套 **56 個檔案、452 項通過**。
