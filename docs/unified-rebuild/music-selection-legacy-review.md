## 確認遺漏並修復

| 項目 | 舊版與修復後行為 |
| --- | --- |
| 選取細分時的程度彈窗 | 選取時先加入預設「常聽」，立即顯示「本命／常聽／聽過一些／只聽過幾首」及原四級說明。關閉保留目前選擇；不自動提交成分。 |
| 已選細分的再次點擊 | 重新開啟程度彈窗，能調整或從已選中移除；不再直接取消。領域維持直接選／取消，不出現程度 UI。 |
| 各入口一致性 | 快速加入、詞庫列表、領域／細分排行、內嵌及獨立網址的詞條詳情共用同一選擇與草稿。關閉子彈窗保留父詳情、來源網址與焦點。 |
| 推薦詞條直接操作 | 共同詞條與對方獨有詞條補回選取操作；既有詞條詳情連結保留。此操作只改本機選擇，推薦仍依已保存成分計算。 |
| 同好成分卡的逐項資料 | 補回逐項複製、分類及選用人數。分類／人數使用既有公開詞庫，無法取得時不補造；複製回饋浮在版面上，不擠動詞條。 |

保留 5 個領域／15 個細分／總共 20 個的上限、既有領域資料值、懸浮保存列、捨棄草稿、版本衝突恢復、未知保存結果去重、帳號 scope 與資料 epoch 隔離。手機程度彈窗採緊湊版面，沿用 Yahha UI。

## 仍存在的差異

| 項目 | 目前狀態 |
| --- | --- |
| 訪客活動摘要 | 舊版公開摘要可見發起者／取消原因。新版會員摘要已恢復，但公開活動契約未提供這些欄位；訪客仍缺少，補齊需要修改公開讀取契約。 |
| 「暫待確認」獨立捷徑 | 待確認報名／確認參加的功能保留於報名表單，也有 `signup?preset=tentative`。詳情少了舊版獨立捷徑，屬入口便利性差異。 |

以下不是功能刪除：活動管理與結算移至已確認的原型分頁；搜尋、詞條、成分卡改為帶網址與來源返回的對話框；QQ／成分 ID 查詢在同好「查詢／比較」；成分資料、聯絡 QQ、自建詞條及分享在我的成分相關頁面。分享仍使用未保存選擇。詞條「誰選了」舊版也沒有逐人程度，不能列為新版遺漏。

活動的同行／代報、候補、認領、補報名邀請、安排確認、管理交接、出席、分房、結算／收付款、圖片與历史，以及投票、帳號／裝置、隱私／恢復、外觀、收件匣和 bot 管理入口仍在。這是來源與入口核對，不能據此宣稱每個功能本輪都已重新驗收。
