# 音樂與同好頁佈局修正

日期：2026-11-24。影響範圍：`web`；發布範圍：`none`，只更新本機預覽。

原畫面直接串接元件，搜尋欄與操作缺少間距；排行以行內文字堆疊，同好卡將所有匹配數據攤開。此次重新安排頁面結構、文字層次與留白，延續 Yahha 的紙面、粉色及深色主題。

- 音樂：頁首操作與次要入口分層，統計獨立排列且在手機縮減高度；搜尋與兩項篩選放在同一紙面。桌面並排領域及細分排行，詞條名稱、名次、分類、選用人數及已選狀態各有位置；窄螢幕依序排列。保留全詞庫、氣泡圖、獨立展開、網址篩選狀態及個人成分選擇。
- 同好：查詢欄、查詢／比較操作保留明確間距；我的成分入口移至頁首。推薦卡依寬度顯示一至三欄，優先顯示名稱、匹配度、共同項與喜好；完整匹配詳情可展開。保留所有推薦、資料較少分組、排序規則、共同／獨有詞條、授權留言與聯絡資料、複製及比較入口。移除領域詞條中沒有熟悉度內容的空白標籤。
