# 共用草稿提示與表單整理

日期：2026-11-26。發布範圍：`web（frontend）`。本次僅本機修改與驗證，未合併、推送或正式部署。

## 行為

- 所有使用共用草稿機制的頁面改用置中的 Yahha 離開確認，提供「繼續編輯／保留原稿並離開／捨棄並離開」。提示不依賴表單的捲動位置。
- 未確認結果的已送出操作使用「保留操作並離開」，保留原請求及操作編號，不提供捨棄。口令仍只在記憶體中；已送出操作編號持久保存。
- 恢復、衝突、儲存失敗及操作結果使用頁面或對話框頂部的浮層。同一個容器中的多份表單共用提示堆疊；非互動區域不攔截下方頁面操作。
- 不顯示逐次自動保存的文案；必要的讀取／保存進度僅供輔助技術使用。提示不插入表單排版，不改變表單高度。
- 重新開啟未提交草稿可恢復或捨棄；保全版本改由「草稿版本」開啟獨立對話框，可下載或載入。載入後關閉版本對話框，回到表單核對。

## 表單與誤判

- 共用標題和關閉按鈕對齊，保留手機安全區；標題、表單捲動區及頁尾各自排版。第二層確認補上遮罩。
- 活動及管理表單的明確欄位使用共用 Field；仍使用原生 select 的欄位保留事件、值及 HTML 表單契約，統一標籤與外形。既有隱式標籤欄位套用同一套樣式。
- 報名管理移除重複名單，顯示所選報名者的狀態；本人無法修改的同行稱呼及付款欄位不再展示為停用輸入。同行、代報、付款鎖定、退出原因及逐人確認規則保留。
- 只切換查看另一位報名者，以及時間投票初始化操作識別碼，均不再誤判為未提交修改。
- 本人直接報名、同行預覽、重要安排確認及結束後連續結算流程保留。

## 原稿保全與契約

捨棄只清除當前可編輯的本機草稿，不更改網站已提交資料，不把捨棄內容新增為保全版本；既有歷史版本仍保留。寫入前核對帳號、修訂號及裝置／音樂刪除／管理撤權 epoch。跨分頁衝突、已失效權限及未確認操作不能被捨棄覆蓋；交易失敗時保留編輯內容及離開對話框並顯示原因。

API、schema、outbox、共用核心、bot 入口和請求格式未改動；本機預覽使用既有隔離的正式資料副本，沒有修改正式服務。未重新整理使用者原本的瀏覽器分頁，也未恢復或捨棄其中的草稿。

## 驗證

- `npm run build:frontend` 通過，包含型別及 HTTP 契約檢查；保留既有非阻擋的動態匯入警告。
- 活動／帳戶／付款／草稿相關 99 項測試首輪 94 項通過；修正報名查看的誤判及舊文案斷言後，12 項針對性測試全數通過，涵蓋原先失敗項目。
- 管理／口令／隱私／音樂工作區／語言相關 170 項首輪 166 項通過；其餘為舊提示角色、版本對話框操作及文案斷言，修訂後納入最後回歸。
- 最新提示堆疊及共用表單的 50 項回歸中 49 項通過，另發現浮層阻擋返回連結。修正點擊範圍後，安排編輯與全部 7 項新草稿測試共 8 項全數通過，無待修失敗。
- 新測試驗證手機捲動後的確認位置、標題對齊、保存期間高度穩定、保留／捨棄／恢復、跨分頁修訂衝突、未確認操作原請求保留、成分捨棄不改已保存資料，以及交易失敗仍保留內容。
- 實際以 430×932 手機畫面核對本機報名對話框的欄位、頂部恢復提示、置中離開確認及遮罩；測完恢復瀏覽器尺寸。其他業務驗證使用隔離測試資料，不向正式 QQ 群投遞。
