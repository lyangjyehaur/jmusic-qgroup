# 全站 Yahha UI 元件核對

發布範圍：`web`（`frontend`）。本次為本機修改與驗證，尚未合併、推送或部署。

## 原因與處理

`kimi-ui.tsx` 的 `Field` 曾保留直接渲染原生 `select` 的相容分支，只加上欄位樣式。`settlement-controls.tsx` 另有一套舊 `Field`，報名、結算、時間投票及部分後臺仍經它直接渲染原生欄位。

現在兩個入口均使用同一轉接層，實際渲染 `yahha-ui` 元件。活動、音樂、同好、帳號、管理後臺、舊資料恢復與隱私流程均已核對。

| 原介面 | 現在使用 |
| --- | --- |
| 原生下拉框 | Yahha Select |
| 勾選框與開關 | Yahha Checkbox / Switch |
| 單選 | Yahha RadioGroup |
| 原生 details / summary | Yahha Accordion，閉合時保留表單掛載 |
| 活動、帳號與外觀選單 | Yahha Popover |
| 未包裝的輸入框與文字區 | 共用 Field → Yahha Input / Textarea |
| 原生 dialog 與候選清除 confirm | Yahha Dialog |
| 遺留原生操作按鈕 | 共用 Button → Yahha Button |

靜態 JSX 核對目前共有 77 處 Select、96 處 Checkbox、2 處 Switch、3 處 RadioGroup、81 處 Disclosure、3 處 PopupMenu，以及 194 處 Field。這是原始碼模板數量，動態列表實際顯示的元件數會隨資料變動。

活動中的 TSX 頁面沒有未經轉接層渲染的原生表單控制。`Field` 子元素仍以 input / textarea 描述欄位屬性，但由 Field 轉成 Yahha 元件。日期、時間、月份及檔案欄位使用 Yahha Input；選取器沿用瀏覽器，元件庫目前沒有對應的專用選取器。元件庫內部的原生 input、隱藏表單值和 option 標記不代表使用者介面仍是原生下拉框。

## 互動與版面

- 保留原 API 選項值，包含空字串；選項重整與重複改值不再清除保存結果或重設確認。
- 保留欄位名稱、必填、禁用、提示關聯、鍵盤選取、Escape 關閉與焦點返回。
- Accordion 的外部展開狀態、深連結和已輸入的表單內容均保留。樣式改為匹配實際包裝層，避免內層展開區套用外層標題大小。
- Popover 內容改為正常排列，使用不透明的主題背景；活動、帳號、外觀選單均檢查裁切與導航後關閉。
- 分房試算為讀取操作，離開可取消等候並保留或捨棄草稿；儲存交易與待確認的正式寫入仍受原保全限制。
- 成員成分彈窗跳往完整成分卡時關閉原彈窗，返回活動後不重開。

## 驗證

建置包含型別、HTTP 契約、簡繁產物和生成檔檢查。E2E 使用每項獨立的合成資料庫，沒有對正式 API 或真實 QQ 群發送測試寫入。

活動／投票／後臺及主要互動 107 項、財務／分房／音樂／草稿恢復 139 項，以及帳號／裝置／隱私／外觀／元件 79 項均已通過（去除 3 項重複，共 322 項）。分批執行，修正後重跑受影響項目；最終 4 項元件核對包含鍵盤選取、深連結展開、選單內容範圍、不透明背景、關閉及焦點返回。

在 430 × 932 的瀏覽器實際檢查下拉框、活動選單、對話框與焦點返回。本機預覽維持 5086，API 使用 5087 的隔離正式資料副本；沒有重新載入或捨棄使用者原分頁上的報名草稿。

未修改 API、schema、outbox、bot、共用契約或現有深連結網址。此紀錄不構成正式發布或 web／bot 組合已切換的證明。
