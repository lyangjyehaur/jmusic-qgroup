# Kimi 接入功能修復與收尾

日期：2026-11-25（Asia/Taipei）。本輪發布範圍 **`web`**：前端互動及匿名統計路由生成修復；沒有改動業務 API、schema、outbox、bot、正式資料或服務。依使用者要求，Docker 留待下一階段；沒有提交、合併、推送或部署。

## 修復內容

- 音樂詞庫及成分編輯器恢復 `/` 聚焦目前音樂搜尋；輸入中、輸入法組字、對話框與被保留的非互動背景不搶焦點。Cmd／Ctrl＋K 在輸入框內仍可開全站搜尋。
- 已選詞條可按領域及四種細分程度收合／展開。領域獨立，不加入程度。補齊手機返回詞庫的可及性名稱。
- 詞庫／成分編輯切換保留搜尋、篩選及來源參數；全站搜尋 → 詞條 → 編輯成分保留「回到搜尋」。
- 已發布活動修改時直接展開進階欄位，顯示重要安排變動必填的修改原因；服務端驗證失敗也會展開。報名草稿恢復後已有備註時，自動展開本人詳細資料。
- 帳號或會員設定子頁已有登入入口時，個人頁橫幅不再重複顯示登入操作。移除無條件出現的「開發預覽」。
- 修正匿名統計產物對巢狀路由的解析：活動下的分享／結算／帳本等路徑使用完整模板，避免全部落入 `/unknown`，不傳送真實 ID 或查詢參數。加入現有單元測試覆蓋活動結算編輯、帳本及錯誤的根路徑。

## 驗收腳本接回實際介面

保留原本資料、權限、草稿恢復、原操作 UUID／內容、儲存失敗不發送、去重、版本及身分隔離斷言。更新測試經由活動「管理」、後台對應分頁、編輯器搜尋加入／移除、成分操作展開、手機固定保存列及目前語意名稱進入功能。

收款圖片隔離斷言限定在收款碼資產，避免將共用頁框新增的頭像當成私人圖片外洩。舊管理原稿遷移失敗測試在頁面初始化時同時注入原稿及 transaction abort，以免頁面先完成遷移才安裝故障注入。未提高時限、增加重試、略過失敗案例或刪除業務斷言。

多批測試可由 `REBUILD_TEST_PORT` 指定獨立服務埠；每案例仍各自啟動隔離資料庫與真實限流計數。完整瀏覽器回歸拆成 5082／5083／5084 三片，每片單 worker、retries 0。
