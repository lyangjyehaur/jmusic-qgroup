# 外觀選單與資訊密度

2026-11-27。本機實作，未部署。發布範圍：`web (frontend)`。

外觀設定沿用 Yahha SegmentedControl，以四個色票呈現苔綠、粉色、淺藍及淺黃；保留粉色預設。明暗模式及資訊密度改為帶圖示的平鋪選項。三組為獨立的單選控制項，保留鍵盤方向鍵、跟隨系統、跨分頁同步、偏好保存及儲存錯誤恢復。

原有 PopupMenu 把標題內容藏在 sr-only，但 Yahha 標題容器仍保留內距與分隔線，因此出現空白標題和一條線。現在顯示實際標題，移除分隔線，重新對齊關閉按鈕；帳號選單以目前稱呼為標題，移除重複稱呼。頂欄選單圖示的一般狀態統一使用 muted 色，保留懸停與展開狀態的主題色。

原型的密度規則被後續頁面轉接樣式蓋過，且只改最小高度時，內距和內容本身仍維持原高度。新增在頁面轉接樣式之後載入的密度規則，實際縮小活動、詞條、搜尋、成員、通知、同好卡片、設定列表、表格及相關區塊間距。文字大小和既有操作按鈕的點擊範圍保留；氣泡圖的幾何位置不改。

壁紙功能已實作：管理員可上傳 PNG／JPG／WebP、管理排序與啟用狀態、設定輪播間隔。一般使用者切換是否顯示全站共用壁紙，沒有個人上傳端點或個人壁紙設定。本次在開關附近標明「壁紙由管理員提供，全站共用」，沒有新增個人上傳功能。

本次沒有修改 API、共用契約、schema、outbox、bot 或網站入口，可獨立發布前端；同分支先前的詞條名稱與鎖定修改仍需要配套 API。
