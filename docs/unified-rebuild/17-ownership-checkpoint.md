# 第十一批實作：管理員核對、修正與解除成分關聯

日期：2026-11-17（Asia/Taipei）。分支：`codex/unified-rebuild`。發布範圍 **`none`**。本輪包含前批找回流程的收尾；未部署，未操作正式 bot、正式資料或憑證。未來正式切換仍先按 **`both`** 準備與驗證，這批合成測試不足以批准單邊發布。

## 新入口與操作

後台的「成分關聯」進入 `/admin/music`，使用同一會員管理角色或獨立救援管理授權。管理員不必先建立自己的成分。搜尋名稱、固定成分 ID、舊查詢鍵、目前聯絡 QQ 或帳號 ID，可篩選未關聯、預先關聯、QQ 授權關聯與直接建立的帳號成分；每頁 20 筆。搜尋內容在 POST body，QQ 不進網址及瀏覽歷史。只回傳 PIN 是否設定，不回傳摘要、OAuth 憑證、私人留言或人工備註。

在 `/admin/music/:id` 核對原稱呼、詞條與程度及目前帳號。輸入目標帳號 ID 或留空解除，填核對原因，先取得含雙方帳號名稱／ID 的預覽，再明確確認保存。目標帳號已有另一份成分、已關閉或不存在時拒絕；不覆蓋成分、不合併帳號、名冊或款項。相同目標只確認目前狀態，不降級原 OAuth 關聯或新增無效歷史。

## 交易與權限保全

- 預覽摘要綁原成分內容／revision、目前及目標帳號、雙方 music epoch。舊預覽遇到成分保存、聯絡號、稱呼、帳號關閉、關聯或 epoch 改變時必須重新核對；包含解除後又關回原帳號的競態。
- 關聯變更、profile revision、雙方 epoch、找回授權撤銷、舊回執失效、追加歷史及最小成功回執在同一 IMMEDIATE transaction。歷史或回執寫失敗，全部回滾。
- 原成分的其他 PIN intents、相關尚未完成的 OAuth attempts、舊 music session／intent 失效。目標剛獲配成分時，其另一份成分找回 intent 也失效；不撤銷與找回無關的普通網站登入或 QQ 綁定。
- 舊保存／聯絡回執轉為 410，避免原帳號在轉走、甚至再關回同一帳號後重放舊內容。舊草稿保留使用者輸入，但 profile ID／revision／epoch 阻止直接改到轉交後成分；明確核對後才可另行保存。
- 清除已被本次決定取代的來源 links／prelinks／overrides，更新 migration map 為 `ownership_superseded`；後續關閉原帳號不會把新持有人標成已關閉。權威 ownership 是目前 `music_profiles.user_id`，來源 JSON 與 native archive 不能重新蓋回它。舊 adapter 仍未啟用，重建／回退投影還須實作及驗收。
- 每次寫入及回執重播重新驗證目前帳號、Origin、一般 CSRF、管理 CSRF 和角色。回執綁管理授權 scope、方法、路徑、profile ID 與完整內容；僅存成功確認，不複製核對原因或個人資料。

## 草稿、歷史與隱私

核對草稿按會員 scope、管理授權 scope、profile ID 隔離，只留在目前分頁。先保存完全相同的 payload 與 idempotency key 再送出；未知回應鎖定輸入，刷新後仍可安全重試，成功後另讀目前狀態。其他管理頁的後續變更不被原成功回執覆蓋。409 保留目標與原因，但撤去原預覽和確認。未保存離開須明確選擇；不可寫或損壞儲存先停止操作並提供保全原稿。

schema 6 新增 `music_ownership_history`，共 80 張使用者表（59 張相容表＋21 張重構／遷移表）。只追加關聯變更；修改／刪除 trigger 拒絕覆寫，只有成分已刪除時才可清理。5→6 不變更既有列、索引或 trigger，碰撞失敗回滾，重開不重複建立。

頁面提供新版關聯歷史及每頁 50 筆游標；遮蔽救援憑證參照，顯示操作者類型或會員稱呼。原匯入 `link_audit` 仍保存在受保護的遷移資料，尚未合流至此頁，未宣稱完整舊歷史 UI 已完成。只關閉帳號時，涉及原持有人、新持有人及操作人的關聯歷史計入共享紀錄待審；刪除成分才一併清理其新版關聯歷史，不假稱全部紀錄已刪。
