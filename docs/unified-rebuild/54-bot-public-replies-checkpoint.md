## 已實作

`@qgroup/bot/public` 與 `.rebuild-dist/bot/public.mjs` 提供原生 TypeScript 指令解析及公開查詢。這是供完整 runtime 接入的函式庫：匯入不開資料庫、不修改環境、不開網路或啟動服務；呼叫者明確提供資料庫或現有檔案、站點 URL 和查詢時間。正式啟動流程沒有切換到它。

- **指令表與別名**：保留六個主面板、26 個標準指令、全部 57 個簡繁及英文別名，包含裸 @、全形斜線、mention 清除與未知指令幫助。`缩写／縮寫／nbnhhsh` 已可解析，但尚未實作非同步縮寫服務；公開查詢型別排除縮寫，錯誤呼叫會明確拒絕，不假裝查詢成功或回其他指令。
- **25 種公開指令**：活動、名額、報名／同行／退出、待確認／確認安排、待辦、出席、結算、我的、地點／規則、發起／再約、款項／帳本／已付款／申報、補報／認領／協辦／管理、往期與幫助。保留必要操作／隱私／回復提示；不增加展示或宣傳文案。寫入類指令只回網站入口與限制，不宣稱已報名、登記付款、授權或建立活動。
- **活動選擇**：公開查詢不要求 `bot_enabled`，排除私人、草稿與已移除活動。原分類、排序、9 筆候選／8 筆顯示／更多連結、限額前排除逾時、當前序號與 8–16 位十六進位短碼均保留。明確短碼可以查已逾時／歸檔的公開活動；錯碼、歧義與越界不回退猜場。往期只列結束／取消，可包含歸檔；財務清單先列終止活動。
- **資料與身份邊界**：名額及出席使用原狀態口徑；待確認不占名額、整組候補不保證直接報上。待辦是公開活動狀態，不是發訊者的個人待辦。結算只回版號、總額、人數與網站同一業務層計算的當前結清狀態；不回逐人金額、付款歸屬、私人備註、聯絡資訊或站內身份。`我的` 不推斷 QQ 與網站帳號關係。
- **名冊與 Markdown**：重用 TS 公開名冊的 party／person 順序、每類最多 10 個名字、Unicode 限長與 mention／連結清理。新增共用 help／command／event／tasks／selection／no-events renderers；使用者資料不產生 Markdown 語法。通用 rich 回覆直接從同一份文字事實組合；相同 read transaction 產生兩種格式，避免兩次讀取之間更新造成矛盾。實際投遞仍須經既有內容長度／域名檢查與政策驗證。
- **唯讀**：檔案入口以 readonly／fileMustExist 開啟，啟用 query_only，不建立檔案或執行遷移；現有 DB 入口也只執行查詢。恢復候選資料庫在任何公開查詢前拒絕，包括幫助。金額格式使用整數處理，最大 safe-integer 分值仍精確。

## 明確修正的舊不一致

1. 舊版 `/发起` 帶參數時，普通文字固定指向建立頁，但 Markdown 會另做活動選擇，可能變成別場選單或沒有 rich 回覆。新版兩種格式都固定為建立頁與「尚未建立」提示；參數不會建立或複製活動。
2. 舊公開查詢對 naive starts_at／deadline 曾以字串與 UTC now 比較。新版沿用已有 TS 活動通知的事件時區規則：例如台北當地 17:00 截止、UTC 10:00 查詢，會正確顯示已截止並提醒成團決策。估計結束仍保留 Python 的「先加 wall-time 時長，再套事件時區」順序，包含 DST gap／fold，不改成簡單 UTC 時差。

除上述有獨立測試的修正外，以實際 Python 輸出作為兼容基線；沒有宣稱每個不規範歷史時間格式皆已完成正式資料核對。
