## 實際資料副本抽查

2026-11-28 10:13:25（台北）唯讀擷取一致性副本：62 個帳號、20 場活動、114 位報名者，schema 15，包含刪除紀錄及圖片。私人副本清除正式身份憑證與待送工作，停用通知和外部投遞，不入版控。

同一正式前端產物搭配實際 API 映像，在本機 Docker 內部網路、唯讀前端、受限 CPU／記憶體／PID 下，以訪客、會員、發起者及管理員各驗證 390／1440px：每種寬度分別 10、19、16、12 頁，合計 **114 次頁面核對**。檢查實際活動／投票名稱、後台帳號數、原成分欄位與領域程度、頁面入口、未處理錯誤、API 失敗及橫向溢出；最終沒有非預期 API 錯誤或橫向溢出。

保留並說明三個 harness 調整：

- 成分後台搜尋是 SELECT-only POST，因初次唯讀 guard 阻擋而失敗；只放行這個查詢後重驗後台，仍阻止所有業務寫入。
- 副本清理移除了 bot_runtime，而實際 API 的後台 bot 契約需要該列；只在隔離資料庫補入沒有 worker 狀態的惰性列後重驗。沒有啟動 bot，也沒有偽造線上 worker 健康；初次 400 保留為副本問題。
- 發起者嘗試開啟已發布活動的私有草稿編輯，API 正確回 409，共兩次；另有驗證正式活動安排編輯頁。這是預期狀態拒絕。

初次 8 項角色／寬度測試為 6 通過、2 失敗；修正查詢 guard 及挑選實際發起者活動後 4 項重驗通過，補入惰性 runtime 後 2 項後台再驗通過。最終八份證據各自包含對應的頁面與 API 狀態。資料副本抽查並未提交所有業務操作，不能取代完整回歸。

另外使用同一擷取時間的資料副本、正式前端包及實際 API 映像，補驗完整跑批中跳過的四個參加紀錄案例：390／1280px 紀錄視窗的可見位置、關閉／Escape／重新開啟、從活動詳情重載後返回同一紀錄、期間與列表／紀錄頁碼、本人紀錄、連續序號與頭像備援，以及 430／1280px 往期未成團狀態與篩選。原本 source-preview 的測試身份入口，改由瀏覽器 harness 授予只在此隔離副本有效的帳號，不增加正式入口。

這四項初跑為 3 通過、1 失敗；失敗是舊斷言仍在狀態欄尋找最低人數，現行介面已將其移至「活動人數」。改為同時核對實際成團人數、未達門檻及未成團狀態後，該項重跑通過，篩選／重載／排除其他狀態的斷言保留。最終四項均有通過證據，沒有以 skip 代替驗收；全部禁止業務寫入與外部網路。

補驗前後核對 96 個資料表的筆數及內容摘要：94 表完全相同；隔離 API 自動建立 5 個本機訪客 session，原生趨勢排程新增 1 筆聚合樣本並按保留上限淘汰 1 筆。`music_documents` 的其他種類均不變。這些變動僅在可丟棄的副本，沒有正式寫入、報名／款項變動、bot 或待送工作；不宣稱 API 啟動後副本的每個位元都保持不變。

兩輪隔離驗證各自的 2 個容器、3 個 volumes 及 1 個網路均已清除；資料與截圖保留於忽略版控的私人目錄，權限受限。

## 驗收界線

本輪可評估目前前端與 API 的接線及覆蓋範圍，並列出可重現缺口；不能宣稱不存在其他錯誤。既有舊台帳 passed、HTTP release-eligible 欄位或健康檢查都不是全站通過證明。

沒有重新驗收真實 QQ 群通知、OAuth 外部官方授權、實體手機的原生分享／圖片長按／PWA 安裝與背景更新，也沒有用正式資料試做刪除、款項或待送恢復。重型遷移／回退測試若逾時，另列未完成，不用單元通過或頁面抽查代替正式維運驗收。

原始跑批、失敗 trace、單獨重測、來源摘要與實際副本證據均保留在私人 `artifacts/private/site-feature-review-20261128/`；沒有提交個人資料、圖片、憑證或資料庫。後續修復應從最新 main 建立新分支，逐項補測後按實際影響範圍發布。
