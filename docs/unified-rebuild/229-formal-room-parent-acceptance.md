## 補回操作狀態

舊編輯器能直接查看未分配人員數量與名單，新共用編輯器先前只有逐房的人員勾選。現在預分與實際包間編輯均顯示「未分配 · N 人」及完整名單；没有房間時直接展開，全部分配後顯示完成狀態，空名冊顯示具體原因。移房／移除房間即時更新，避免逐房展開才發現漏人。

預分遇已不在名冊的人員時，提示核對並移除；「重新納入結算」只在實際結算顯示。沒有新增裝飾文案、重算資料或改變確認／保存流程。

## 保留原字串處理

原 Python `strip()` 與 JavaScript `trim()` 對少數 Unicode 字元不同：NEL／record separator 應從邊界移除，BOM 則應保留。共用房名、預分原因及舊原始請求恢復現在使用既有 `originalString`，與固定 Python 的房間、原因、稽核及實際房間預覽核對；不更改穩定房 ID、原 payload／簽名或舊快照。
