# 按預定結束時間歸類往期活動

2026-11-25。發布範圍：`web`。依使用者要求，活動到達「開始時間＋持續時間」後直接歸入往期，無須發起者確認結束、結算或歸檔。現行建立表單必填持續時間，後端接受 1–24 小時，預設 3 小時；唯讀核對時，正式資料沒有缺失時長的活動。

列表、搜尋／狀態篩選、分頁總數和近期摘要使用同一分類；過期活動從個人首頁的目前活動中移除，完整「我的活動」仍保留所有相關紀錄。列表及個人首頁每 30 秒更新。過期但未確認實際結束的活動顯示「已過預定時間」，詳情仍保留實際結束待確認提示；延長安排後，新的結束時間尚未到且沒有實際結束／取消／歸檔時回到近期。

不改寫 events.lifecycle、actual_ended_at、結算／金流／名冊或 outbox。原有結束、取消與歸檔分類仍保留；公開／邀請／草稿／刪除與帳號 scope 權限不變。新舊 API 的資料契約和 bot 所用的共用業務規則不變。核對 repositories.ts 的完整差異後更新 HTTP access review pin，沒有改動其權限條件。

已通過：31 項 API／領域／生命週期測試、15 項瀏覽器頁框／生命週期回歸、建置、編譯產物 smoke、型別及 diff 檢查。新增案例覆蓋結束前一毫秒／結束當下、scheduled／ongoing、跨日與 offset、未結算／已有帳單、延長回到近期、搜尋／分頁／摘要、讀取不改寫業務與通知、過期標籤、個人首頁空狀態及結算入口。瀏覽器的過期投影案例以攔截讀取回應驗證顯示，真正後端歸類由注入時鐘的 API 案例驗證，沒有用修改正式活動來驗收。

本文件描述功能與本機驗證；正式發布結果另記 release 文件。
