## 補齊結清稽核與原表單上限

隔離原款項演練發現：原 Python 把結清稽核的 `last_seq` 存成 JSON 整數，新版稽核曾存成字串。帳本本身與 HTTP 字串序號正確，但稽核型別未一致。財務稽核改用已有精確整數序列化器，保留完整整數 literal；共用追加的其他呼叫維持原 JSON 處理。不修改任何原稽核列或歷史。

超過 `2^53` 的單元案例同時驗證 HTTP／頁次／預覽憑證、帳本和稽核的原精確 checkpoint；正式副本三份帳單的六次結清稽核由獨立 Python 證明為整數。額外款項人員新增按鈕改為兩人封頂，與原程式／共用契約一致；移除後可再新增，既有草稿仍可保全或逐項移除，已確認帳本補回舊介面原有的結清版本，並保留該次帳本檢查點；重新開啟後仍可核對原結清紀錄。不增加展示文案。360px 包間資金摘要改用既有 finance-facts 欄位對齊，讓店家支出等名稱不被窄欄拆斷，金額保持右側對齊。
