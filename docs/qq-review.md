# QQ 互联送审文案

## 应用名称

群聚看板

## 应用简介

面向群组成员的活动报名与协作管理工具，支持聚餐、运动、出游、唱歌等活动的发布、报名接龙、人数统计、候补管理、站内消息和费用分摊记录。用户可通过 QQ 登录管理自己的活动与报名信息，方便组织者和参加者协调安排。

## 简短版本

群组活动报名与管理工具，支持活动发布、报名接龙、人数统计、候补管理和费用分摊记录，方便成员协调聚餐、运动、出游、唱歌等活动。

## 功能说明

提供活动安排、报名和费用记录，不执行真实转账。QQ 登录用于站内账号登录与找回；以平台实际授权成功为验收标准。

页面名称、活动发布入口与在线说明统一采用「群聚看板／活动」。唱歌仍是可选活动类型；不因改名改写用户填写的标题、地点、历史和分类协议值。
