# 報名成功主動群通知

已於 2026-11-11 15:58（Asia/Taipei）成套部署，並啟用新通知種類（設定 3 → 4）；詳見[發布紀錄](releases/2026-11-11-bot-signup-notifications.md)。

發布範圍：`both`。web 的報名審計在同一事務產生 outbox，bot 依新通知種類投遞，後台共用設定列出「有人报名」。本文件為實作說明，正式結果另記於發布紀錄。

- 新增 `registration_added` 通知種類及標籤；普通報名、待確認轉為正式／候補、接受補報邀請時，比較此次審計前後人員，只列從非正式／候補進入正式／候補者。既有候補遞補不算新增報名，不附帶其他人的變動。
- 一次操作一則，包含本次新增人員（正式／候補分開，每類最多 10 名及其餘人數）、當時總人數、開始倒計時及活動入口。只使用既有的安全顯示名稱，不序列化審計內的備註、付款歸屬、帳號或人員 ID。模板可用 `{details}` 放入系統說明。
- 純待確認、生成邀請、編輯稱呼或付款歸屬不通知。建立／發布活動時自動報名仍保留原審計，僅抑制其額外 bot 掛鉤，完整名單併在活動發布卡。
- 依現有公開可見性、活動同步、全局開關、通知種類、指定目標群、勿擾、間隔、模擬及重試政策；普通訊息凍結入隊事實。回滾同時取消 outbox，審計重複掛鉤按事件 revision 去重，HTTP 重複提交沿用 Idempotency-Key；不補發歷史報名。
- 不新增 schema 或設定欄位。新配置預設包括新種類；已儲存的 `broadcast_kinds` 原樣保留，需明確增加此種類。舊版後台驗證不接受新 enum 或相應模板 key，故按 `both` 發布；回退前要在新版設定移除 `registration_added` 及其模板再恢復舊版本，保留其他設定與現有資料庫。不能把舊版能讀 SQLite 當成完整回退相容性。

測試在隔離資料庫及模擬 QQ API 執行，不會對真實群聊發測試通知。

本機驗證：新增 11 項報名通知測試，完整 Python 測試在 bot 開關 `0`／`1` 各 499 項通過；Node 11 項通過。手冊與簡繁產物已重建，`git diff --check` 通過。
